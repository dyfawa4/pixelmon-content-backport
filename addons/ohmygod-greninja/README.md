# 我的天哪忍蛙大人

这是回迁核心1.7.0的可选增强附加模组，默认不安装。

基础核心的小智忍蛙飞水手里剑没有水系增益，孤忍自修没有额外行动。把`ohmygod-greninja-1.16.5-1.0.0.jar`放入`mods`后，恢复原先飞水手里剑五回合水系威力×1.5，以及孤忍自修额外行动与个人计时。其他规则保留。两招游戏内说明自动切换。

客户端与服务端都需要安装本模组和同一份最新回迁核心，联机校验要求两边模式一致。删除本模组即可回到基础规则，不删除存档里的宝可梦或招式。Minecraft1.16.5、Forge36.2.42、Java11。

测试包把本模组放在`可选模组/`目录，需使用时自行移动到双方的`mods/`；不要把可选目录当成已经启用。

孤忍自修新核心统一增加“下一回合招式优先度+1”，基础版与本附加模组都生效；本附加模组额外恢复原有额外行动。换下清除，不叠加。
