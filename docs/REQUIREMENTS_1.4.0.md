## 1（修复）：进化获得的传说成就

科斯莫古成功进化为科斯莫姆，以及后续索尔迦雷欧/露奈雅拉，应完成对应成就。全面核对其他由进化实际获得的传说、幻兽、究极异兽等，不把合法获取限定为捕捉。只在成功、未取消、服务器端、属于玩家的真实存储对象完成进化后检查；不以预览、临时战斗形态、失败或蛋触发。保留原成就 ID 和要求，兼容本体与回迁成就。

## 2（修复）：巢穴捕捉触发本体成就

原生极巨巢穴与回迁太晶巢穴成功捕捉传说宝可梦，应检查重铸本体的物种/形态成就，并继续完成回迁成就。失败、取消、未实际入队/PC 或他人捕捉不计；不因重复事件重复给予奖励。保留本体其他成就条件。

## 3（改进）：群聚变形基格尔德的场外 J 流程

拥有群聚变形（Power Construct）的基格尔德，通过场外 J 先变为完全体；完全体持有匹配 Mega 石时，再次 J 执行场外 Mega 进化。普通光环破坏特性不开放完全体入口；保留已有 UUID/等级/训练/选中宝可梦校验、正常变身与还原、原生进化事件及资格，不绕过战斗中限制。

## 4（修复）：小智皮卡丘显示
