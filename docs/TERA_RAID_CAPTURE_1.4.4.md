# 太晶巢穴捕捉与极巨巢穴统一

2026-10-16，核对源码、1.4.4 原测试构建及电脑端已安装 JAR：旧实现 `TeraRaidCatchMixin` 在 `tryCatch` 入口遇到太晶奖励标记时直接返回 4，原生团战将此值视为捕获成功。因此旧太晶巢穴胜利后对合法球通常保证捕获，与极巨巢穴不一致。

经用户确认，1.4.4 移除这条保证捕获分支。太晶和极巨巢穴均调用当前重铸本体的 `RaidData.RaidPlayer.tryCatch`，由所选球的 `CaptureMethod.calculateCapture`、原生 `CaptureHealth`、目标数据及捕捉事件决定结果。不新增固定百分比、不另乘捕捉倍率；相同条件使用同一公式，不表示不同物种和球种的成功率相同。

保留禁止球检查、胜利奖励、太晶属性和形态保存、原生扣球及成功／失败事件。爆裂场地仅对本场符合条件的玩家保留已约定的合法球有效倍率加 1，同时恢复太晶捕捉阶段相应黄边提示；无场地不加成。普通野外 Boss 禁球与巢穴战后捕捉仍分别处理。

`RaidCaptureParityVerification` 检查真实本体应用 Mixin 后仍保留唯一原生球计算与摇动结果调用，不再读取太晶标记绕过概率，入口仅拒绝禁止球。整套 `check.ps1` 已通过。手动地图的捕捉／扣球冒烟用例改用原版大师球，避免普通球随机失败造成误报；只改测试源码，不提高生产捕捉率。

已用 Java 11 启动独立客户端供用户实测；用户已确认本轮测试没有问题。
