# 1.4.3 离线测试包：先读我

修订 2 构建标识为 `1.4.3-offline-test-r2-20261015`：增加 FTB 模组结构任务兼容、戴帽子皮卡丘战斗捕捉提示，以及 Lootr 启动联网等待防护。已有首份包只需替换主模组 JAR；无需覆盖已经测试的存档。详细范围见 `docs/REVISION2_1.4.3.md`。不新增任务书地图，不加入地牢定位。

适用现有「宝可梦：轻快之旅」整合包的独立测试副本。环境为Minecraft 1.16.5、Forge 36.2.42、Java 11，重铸本体文件名9.1.13、内部版本9.1.12。**本包是补丁与地图包，不是完整游戏客户端**；使用测试员已经安装好的整合包启动，无需连接本项目服务器或登录GitHub。

## 安装

1. 正常退出游戏，在整合包副本中操作。备份要保留的世界。
2. 从该实例的mods移除旧版`pixelmon-content-backport`，以及旧独立补丁`pixelmon-jei-fix`、`pixelmon-raid-catch-fix`。保留重铸本体、JEI、探测器和其他原有模组。
3. 将本包mods里的两份JAR复制到该实例mods，只保留一份主模组和一份地图配套。游戏应显示主模组1.4.3。
4. 将saves中的地图文件夹复制到该实例saves，不要把不同世界的文件合并。包内共11张地图：9张功能图、1张最新已验收岩石城、1张智皮卡图。
5. 正常启动游戏，选择地图。蓝绿色控制台需空手右键方块本体。部分场景首次进入会搭建，等待设施生成后操作；不会自动对战或替代人工验收。

建议先测`02 换形与技能回忆`、`05 太晶巢穴与掉落`和`回迁道馆 1.4.3 岩石城已验收布局 [rock]`。岩石城使用已验收97片段快照，不选旧版岩石图。本包只收录这一份岩石城。

## 自然刷新必须另建正常世界

功能平台关闭一般刷新，不能用它判断自然巢穴、传说和府邸刷新。新建正常世界，使用整合包原有群系生成设置；测试BOP府邸需保留超多生物群系模组。需要旧档兼容时只用旧档副本。

自然巢穴按固定种子和坐标约各50%分流，并不保证小范围、当前活跃巢穴或沿引导线看到的数量恰好一半。太晶与原生极巨的活跃／空置轮换不同。不要仅凭引导线数量判断生成比例。
