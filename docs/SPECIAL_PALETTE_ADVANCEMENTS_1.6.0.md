触发条件：自己实际获得并存入队伍或电脑的对应物种、材质、形态；沿用任务书的非闪光限制，蛋不计入。旧存档登录时补查。材质或形态转换后也会检查，谢米陆上／天空分别判断。普通材质、错误物种和仅复制存储坐标的非真实入库对象不会触发。

这些是获得材质的游戏成就，不会自动完成 FTB 任务书的拍照任务，也不会重复发放任务奖励。完成其中一项即可沿用现有成就分支规则开启“传说续章／传说异姿”。

来源：`5280BD560935AC78.snbt`；每个任务 ID 保存在 `resources/backport/special_palette_advancements.json`。生成脚本 `tools/build_special_palette_advancements.py` 会核对本体物种标签、材质和形态，再生成成就资源。

验证：12 项对应资源和任务名一致；实际生产判定的跨物种、普通材质、错误形态、蛋和闪光负例通过。生产授予链经原生 PCBox 插入与持有者查找验证，包含旧的真实入库／克隆拒绝边界。
