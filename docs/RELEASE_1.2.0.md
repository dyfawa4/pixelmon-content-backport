# 重铸内容回迁 1.2.0

补齐十八种属性道馆与对应徽章，新增一般、格斗、毒、飞行、超能力、虫、岩石、恶八类主题城市。八座新城重新设计主道馆、住宅与公共设施，扩充街区与奖励箱，各有不同的建筑轮廓、材质和主题地标；保留原生 NPC、商店、宝可梦中心等服务，并按主题接入自然生成群系。

修复原有部分馆主缺少徽章奖励的问题；新增徽章提供 Shift 详情与 JEI 用途/来源信息。新增十八张独立完整城市测试地图，以及全部十八枚徽章的展示地图。

优化实力相当 NPC 的对战逻辑。

- 新八城 v5 补齐主题场地、观战席、照明、馆主背景、训练与观测设施和街区景观；格斗道场结构重做，飞行场地增加风向标与观察设施。
- 住宅/公共设施安装正式门，清空门前门后两格净高通路；玻璃板和承重组件通过独立几何检查。
- 修复预览地图把可选树木生成失败误判为整城失败的闪退；真实建筑放置失败仍报告错误。
- 补齐 162 份原生 NPC 中文对白资源，共 1156 行；Pip 等对白已翻译，原商店/队伍数据保持一致。
- 修复新增成就头像，分组入口统一大师球；四项指定成就名称更新。JEI 正文黑色，Shift 详情灰色。
- 增加 `/locategym <属性> [半径]` 和十八属性探险家指针入口，目标按真实主道馆筛选；避免旧属性搜索覆盖新坐标。

- 新增场外 Mega 进化及还原，默认 J，可在控制设置中修改；圆形菜单上方 Mega、下方原生场外技能，中央显示选中的宝可梦，支持切换已放出对象；复用原生动画与合法进化石，进入战斗或收回等情况自动还原。
- 合体成就明确写出双方、道具与目标形态；补充无极巨化成就。
- 移除重复的快龙进化石，旧存档中的重复石自动转换，并保留数量与自定义数据；十八张城市地图新增出生传送台，可直达道馆、城市和公共设施。

- Shift 物品详情统一为灰色；已充能太晶珠显示原版附魔光泽，未充能保持原有外观；说明统一“治疗仪”用语，右键操作提示单列第三行。
- 本体已有快龙进化石时优先使用原生石；本体缺少该石时提供唯一的回迁石。
- 为破空焰、猛雷鼓、铁磐岩、铁头壳补充原生地面骑乘，不为小体型物种强加骑乘。
- 新增“传说续章”：104 项第四至第九世代传说、幻之宝可梦、究极异兽及悖谬宝可梦捕捉成就，以及 6 项原生合体成就。已有任务名优先沿用，实际捕捉和完成合体才触发。
- 成就使用普通节点，阿尔宙斯保留挑战；专项地图可右键分类台点击中文名字生成指定对象，并直接准备真实基格尔德与完整圣杯合成流程。
- 针对基格尔德多面体界面的未同步队伍/缺失招式、天界之笛合成的缺失玩家记录/越界动画增加保护，保留原生操作流程。
- 修正索财灵硬币用途的说明，使之与本版实际道具右键进化流程一致。

原七张功能地图继续保留，增加骑乘、传说成就与合体两张专项地图；连同城市和徽章展示共 28 张独立地图。地图包顶层直接为 `mods/` 与 `saves/`。

本版按用户授权发布。Java 11 构建和程序检查见 [验证记录](VALIDATION_1.2.0.md)，完整实玩由测试员验收。升级时移除旧版回迁功能模组和旧地图控制模组，各保留一份新版；不要安装内部自动测试模组。新增城市需探索新区域，已生成的旧城区保留。
