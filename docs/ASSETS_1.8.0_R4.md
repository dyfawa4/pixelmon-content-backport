# r4 像素灯素材

用户确认以之前游戏里的银白色立体灯为准，不采用r3科幻枪造型。使用imagegen内置工具，参考r2游戏截图底排原灯，输出透明像素图，再裁去透明留白、最近邻导出32×32；两图主体统一28×28、四周2像素留白。

Simple three-quarter isometric view, 32×32 conceptual pixel art, transparent background, compact original block silhouette; no circular lens, diagonal gun, vents, buttons, long barrel, text or frame.
