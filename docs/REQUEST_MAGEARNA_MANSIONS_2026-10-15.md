# 玛机雅娜按林地府邸结构刷新

用户反馈：超多生物群系使林地府邸可在非黑森林群系生成，而玛机雅娜仍受黑森林限制。要求所有群系的林地府邸均可生成；随后明确「变成结构生成吧」。

本轮按真实林地府邸结构判定刷新资格，去掉原生规则的`roofed`群系条件；保留白天、室内、白桦木板、50级、传说刷新计时及稀有度0.3。没有把每座府邸改成固定生成一只，也没有提高刷新概率。

通过已加载的原生`legendaries/magearna.set`规则进行合并，不新增第二份刷新池；实际结构查询使用林地府邸跨区块引用及片段范围，普通房屋不满足。仅玛机雅娜使用此结构桥接，既有智皮卡村庄逻辑及其他物种保持原样。GitHub发布继续暂缓，已验收岩石城快照保留。

验证结果补充在`VALIDATION_1.4.3.md`。
