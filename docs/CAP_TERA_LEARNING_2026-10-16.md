# 智皮卡学习太晶爆发修复

1.4.4 修订，2026-10-16，包含于本次发布。

智皮卡是独立的 CapPikachu 物种，图鉴编号 1026。生成物种时会复制原生皮卡丘的完整招式表；共享太晶爆发兼容补丁在此后才应用。原共享白名单没有独立种类 1026，而复制表也没有太晶爆发，因此智皮卡未获得第九世代 TM171 的学习资格，使用光盘会显示「无法学习 太晶爆发」。

本次将 1026 的基础形态加入共享白名单，沿用其他支持物种的规则：原版第九世代太晶爆发光盘与本模组的一次性光盘都走原生兼容检查，50 级学习／回忆数据也一并补齐。保留原生招式、智皮卡额外配招、专属招式、性别、种族值、特性、Z 与爆裂场地规则。既有个体在物种数据重新加载后获得兼容性，不自动替换现有四个招式。

提取同一既有 JSON 处理步骤为 `Content.applyTeraLearning`，加载器仍在智皮卡生成后逐物种执行。回归执行生产步骤，先复现本体皮卡丘复制表缺少太晶爆发，再验证 TM9 资格、50 级回忆、原招式保留、非招式属性未变、重复加载无重复与普通皮卡丘兼容。未以隔离测试冒充玩家实机学习通过。
