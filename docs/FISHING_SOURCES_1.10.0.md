# 钓鱼产物与条件查询（1.10.0）

在JEI中对宝可梦钓竿、好钓竿、厉害钓竿按U，选择“钓鱼产物与条件”；对能钓出的物品按R也能查看来源。宝可梦以原生宝可梦图标列出，分类可翻页查询。正文显示条件摘要，悬停产物图标查看完整条件。

候选表来自服务器当前已加载的钓鱼生成器，包含宝可梦与物品，保留内外层奖池约束。每条列出适用钓竿、水域或岩浆、群系／群系类别、时间、天气、维度、高度、天空、排除条件及其他原有条件；宝可梦另列等级、个体配置，物品另列数量。群系类别对应当前服务器配置所展开的群系，不把类别硬写为单一群系。复合可选组满足其一，复合排除组满足任意一组即排除。

例如当前原生欧米伽碎片条目需要厉害钓竿在干旱类群系的岩浆中钓鱼；沙漠属于该类别。不是随意水域，也不是附魔足够就能绕过地区限制。具体类别覆盖的群系仍以服务器加载结果为准。

权重与配置百分比注明所在选择层，均不能直接当作每竿最终概率。可否咬钩、当前可用候选、各层奖池及附魔都会影响实际结果。本查询不抽奖、不投放宝可梦、不消耗道具或改变钓鱼机制。

客户端和服务端均需更新r8核心；来源同步协议为3，重连或服务器重载数据后更新候选表。
