# 重铸内容回迁 1.10.0

适用于 Minecraft 1.16.5 / Forge 36.2.42 / Java 11 / Pixelmon 9.1.12～9.1.13。正式版采用已完成后台验证的 r12 核心，汇总 1.9.0 之后的更新。

## 下载与安装

一般玩家下载 **Pixelmon-Backport-1.10.0.zip**。另提供独立核心、源码、玩法手册与 SHA256 校验文件。

关闭游戏与服务端后，双方替换旧回迁核心，mods 中只保留一份 1.10.0。保留 Pixelmon 本体、依赖和存档；无需独立资源包。本包不是完整整合包，不含游戏本体、个人存档或测试助手。

包内 config 目录用于关闭万能熔炉更新提醒，覆盖到实际客户端实例后重启。可选忍蛙增强为 **1.0.3**，默认不启用；需要时双方另装并替换旧增强模组，功能规则保持，扩展核心版本兼容范围。

## 果实收集器

新增专属立体模型与像素贴图，右键成熟树果／球果叶，最多连锁采收20片相连叶。果实直接进入背包，满包时落在脚下；保留树叶，未成熟、无收获或交互被禁止时不扣耐久。

耐久10点，每次成功采收扣1点并播放一次拾取音效。支持时运和耐久，所有支持的附魔仅能通过附魔书在铁砧添加，禁止经验修补与消失诅咒。每颗钻石恢复3点耐久，只消耗所需数量；钻石修理保留已有铁砧惩罚值，不再累加，不清零旧惩罚；附魔书合并规则保持。

工作台产出1件：

| --- | --- | --- |

也可从史诗、传说、终极、溺水 Boss、作者道馆及林地府邸宝箱奖励中获得。详见随包《果实收集器与说明更新》。

## 进化、JEI与界面

- 同行菜单新增“进化”，详情页在概要／招式／能力后增加同级标签，在原面板显示普通／分支进化、Mega及形态变化条件，道具、等级和特殊条件分别展示。
- 完善进化图标对齐、箭头、字体、分页与武道熊师流派名称，修正多默认形态查询引起的闪烁；修正基格尔德 Mega 普通／异色图标。
- 所有物品悬停直接显示完整说明，无需按Shift；说明统一放在灰色注册名之前。指定道具与咖喱食材说明更新，保留JEI获取信息。
- JEI新增食物／药品及全部可购商品的店员、售货机、掉落、料理锅和奖励箱来源；店员显示候选商品及基础价，实际库存以商店界面为准。物品按R查来源，售货机按U查看商品。
- JEI新增钓鱼产物与条件：钓竿、物品／宝可梦、群系、时间、钓鱼介质等限制。钓竿按U查看，产物按R反查。
- 随包提供新增与全部Mega Boss刷新地点Markdown表。

## 钓竿、道具与配方

- 三种普通宝可梦钓竿支持同时附魔海之眷顾、时运、抢夺；总等级1～9对应三感叹号特殊事件概率10%～90%。时运与抢夺仅能通过附魔书铁砧添加，附魔台不能获得。
- 总等级大于0时，成功钓起基础扣“总等级＋1”耐久；零等级不额外增加事件概率、不扣耐久。空竿、脱钩或取消生成不扣，保留原生耐久附魔减免及创造免损。地点等候选条件仍然适用。
- 补充并调整咖喱食材配方，特选苹果改为9苹果；危险之汤新增6普通金苹果＋碗；JEI说明同步，移除食材任务领取指引。
- 两种宝珠可无序分解回9个对应碎片，支持2×2合成栏。
- 耀光球增加附魔光效，任务书准确区分球种；配方的菌光体、荧石改为光鳞粉。光鳞粉仅由真正异色且非Boss的宝可梦掉落，特殊皮肤不再视为异色。
- 除虫、白银、黄金喷雾的道具和使用提示统一为一段时间内周围不再生成宝可梦。
- 删除铜熔炉升级银熔炉、铁熔炉的两条指定配方，其他配方保持。

## 对战与探索修复

- 优化AI战斗逻辑。
- 道馆性格按最终配置选定；所有训练家对战入场检查双方重复携带物，NPC自动调整，玩家仅提示调整。平时和野外不限制，不删除道具。
- 获得“这么强？！？！”成就后再次挑战作者，作者存活不超过3只时开启贯通：作者攻击玩家的属性克制倍率至少3倍，原本4倍保留；玩家攻击作者的倍率不变。复活到4只关闭，回落到3只重新开启。未首胜者难度保持。
- 修正NPC能力值重算覆盖临时战斗等级的问题；修正太晶爆发学习适配及一次性光碟确认流程、小智忍蛙场外进化石匹配。
- 太晶化与其他战斗变身入口／图标互斥；跑蛋机不再持续弹动放出宝可梦时的精灵球。
- 克隆机修正渲染状态对周围模型及透视的影响；冰箱／玉石补齐上半部占位、命中、放置坐标、完整框和Jade提示，旧重叠方块不直接删除。
- 冰箱新增木桶开关音效，多人使用时首位打开、末位关闭；Jade补齐宝可梦、NPC、船与两种巢穴中文显示和有效命中。
- 两种巢穴手动投入许愿石不受自然刷新区域上限限制。退出／认输／强制结束不再误播胜利音效。
- 作者道馆在究极发电厂使用海晶灯；地面道馆排除究极深海，普通恶地保持；岩石道馆仍仅在究极沙漠，徽章JEI说明同步。生成规则修正只影响后续新生成，已有建筑保留。
