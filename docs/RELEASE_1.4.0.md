# 重铸内容回迁 1.4.0

发布日期：2026-10-13。Minecraft 1.16.5 / Forge 36.2.42 / Java 11。

本版加入独立智皮卡、专属 Z「雷之起源」与持续爆裂场地，修复传说获得成就、巢穴捕捉与道馆对战，并补齐图鉴和中文界面。玩家已确认本轮验收合格，按确认版本发布。

## 智皮卡与专属 Z

- 独立种类 `CapPikachu`，中文「戴帽子的皮卡丘」，编号1026，纯电属性、电气制造者，种族值135/65/120/175/100/125，合计720；不能进化或培育。
- 仅在真实平原村庄按原生神兽计时刷新，等级70。配置刷新概率减去40个百分点、下限0（70%→30%），原生位置与候选选择仍生效。
- 原生捕获率参数3，属于极难捕捉；不是固定3%。大师球、公园球、起源球禁止用于捕捉智皮卡，其余合法球仍按原生公式尝试。
- 保留完整原生皮卡丘学习池，新增冥想、伏特替换、能量球、真气弹、诡计、过热、精神强念，基础回忆招式「千万伏特」为电系特殊120威力、100命中、基础PP5。
- 四个皮卡丘 Z 无序合成一个智皮卡 Z。给独立智皮卡携带智皮卡 Z、满足原生 Z 手环与对战资格后，将千万伏特转换为185威力的「雷之起源」，遵守原生每场一次 Z 限制。普通皮卡丘不能响应本版专属转换。
- 雷之起源仅对可正常投球捕捉的单个普通野生目标将直接伤害限制到1HP；玩家、NPC、馆主、Boss、原生/太晶巢穴及不能投球的对战使用全力。
- 专属 Z 展开爆裂场地，未被其他场地覆盖就持续到战斗结束。展开方电属性宝可梦的电招对非中性倍率×1.25，对手攻击展开方电属性宝可梦的非中性倍率×0.75；1倍与0倍免疫保持原生。原生电气场地接地效果继续生效。
- 展开方本场适用精灵球的有效捕捉倍率加1，不解除禁球或其他限制。受益技能与球显示贴合原生按钮的黄色边框，队友及太晶爆发等变属性招式按当前真实条件判定；右侧显示「爆裂场地」。

完整属性示例、技能渠道、升级兼容、投球流程和提示边界见 **[智皮卡与智皮卡 Z 详细玩法](CAP_PIKACHU_1.4.0.md)**，完整手册亦收录同一说明。

## 成就、道馆与城市修复

- 传说、幻兽与究极异兽按实际获得触发原生及回迁成就，支持进化、原生/太晶巢穴捕捉和真实同行/PC存入；复核科斯莫古系列、属性空→银伴战兽、毒贝比→四颚针龙等进化路径。
- 普通三圣鸟与伽勒尔形态成就分开。伪装百变怪在揭露与实际存入后按真实物种判断，修复「乔装打扮」，不再错误授予被伪装种类的美录坦成就。
- 新增代欧奇希斯真实形态转换成就「千变万化」及智皮卡获得挑战「最好的伙伴」。已完成成就保留原ID与进度。
- 十八属性真实馆主基础奖金提高到20万宝可元，仅馆主给予徽章。格斗王牌使用成熟强力传说，恶系王牌不再错误使用超梦，原十城与新八城同步；保留合法满配、原生等级缩放及特殊机制。
- 修复馆主超进化与反伤倒下交错导致 Waiting 卡死。对战冻结运动时避免继续鞘翅飞行、下落或沉水，改善角色抽搐；聊天、指令及合法传送继续可用，战后恢复。
- 保留确认的 v9 建筑，将岩石城中央砂岩堆改为沙漠神殿；城市规划范围内避免后生成的自然水坑、树木与植被破坏建筑。既有损坏区块不自动重建。
- 自制城市NPC姓名与对白补齐中文；野外大师球奖励箱过滤无效空奖励并提供保底；任务书商店显示中文「商店」。
- 群聚变形基格尔德可按 J 场外转完全体，再携带匹配进化石与手环继续 Mega；烈空坐学会画龙点睛并装备 Mega 手环，可按 J 场外 Mega，不要求进化石。场外临时形态遵守收回、入战与失效还原规则。
- 新增第九世代宝可梦图鉴栖息地接入实际刷新规则；方块、机器界面及可选 PixelTweaks JEI 配方标题统一为「树果炼制器」。

任务书目标、奖励与任务条件交由任务书维护者处理，本版未修改这些内容；成就触发与任务书的独立物品检查不等同。
