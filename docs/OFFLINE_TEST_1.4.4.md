# 1.4.4 离线测试包：先读我

构建标识 `1.4.4-offline-test-20261016-r8`。新增太晶巢穴与极巨巢穴共用原版捕捉公式，移除太晶保证捕获。追加宝可梦编辑器中文物种、球种、招式、携带物输入与双语补全；包含联机其他玩家跨维度 TP 导致房主对战崩溃修复。包含神兽直接入 PC 的成就、剑／盾之王实际变形、Z 招式预览崩溃、全部野外 Boss 禁止投球，以及普通初始宝可梦误完成「奇装异服」。另含 2026-10-16 智皮卡太晶爆发学习、Java 11 强制门禁与新版任务书磁石兑换移除。此前追加的回忆师适配已取消。包含于 1.4.4 发布；本轮测试客户端已由用户确认通过。

**沿用之前的补丁与地图包格式，需要测试员已有的「宝可梦：轻快之旅」整合包；本包不含完整游戏、启动器或 Java。** 适用 Minecraft 1.16.5、Forge 36.2.42、Java 11，重铸本体文件名 9.1.13、内部版本 9.1.12。安装后使用原启动器正常启动，无需下载本项目文件或连接测试服务器。

## 安装

1. 正常退出游戏，使用整合包的独立测试副本，备份需要保留的世界。
2. 在该实例 `mods` 中移出旧版 `pixelmon-content-backport` 和旧地图配套 `backport-test-maps`，以及已整合的独立 `pixelmon-jei-fix`、`pixelmon-raid-catch-fix`。保留 Pixelmon 本体与整合包其他模组。
3. 复制本包 `mods` 中两份 JAR，主模组与地图配套应各保留一份 1.4.4。联机测试的服务端与客户端主模组版本需一致。
4. 将本包 `saves` 中各地图文件夹复制进实例 `saves`。同名旧测试世界如需保留，应先改名另存；不要合并世界文件。
5. 此修订包的 `config/ftbquests/quests/chapters` 有两份新版“电脑端”任务书章节覆盖；在同版任务书的测试副本中备份后复制，删除磁石循环兑换及无用收费入口。不要覆盖自行编辑过的不同版本任务书；统计见 `docs/QUEST_MONEY_2026-10-16.md`。
6. 通过原启动器打开整合包，手动选择地图。蓝绿色测试控制台空手右键方块本体；首次进入可能搭建设施，等待完成。没有自动战斗或自动开图工具。

本包共 11 张干净初始地图：9 张功能图、1 张用户满意的最新岩石城、1 张智皮卡图。岩石城使用 `backport-gym-v143-rock-vanilla` 的已验收 97 片段快照；名称中的 v143 是地图标识，包内主模组是 1.4.4。未加入新的任务书地图或地牢定位功能。

## 优先测试

先按 `测试清单.md` 验证开局成就、满队捕捉进入 PC、剑／盾变形、Z 招式和 Boss 球类入口。旧存档已有的误发成就不会自动撤销，开局误发请用干净世界验证。非对应物种不应误解锁；普通伊布、未知图腾、小陨星仍保留原生根分支开启规则。

自然巢穴、传说和府邸刷新需要另建正常世界并保留原群系设置，功能平台不能用于判断自然比例。两类巢穴按种子／坐标约各 50% 分流；引导线仅显示符合当前状态的对象，不代表实际生成总数。
