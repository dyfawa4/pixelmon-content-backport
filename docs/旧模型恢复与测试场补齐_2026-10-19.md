# 旧模型恢复与测试场补齐（2026-10-19）

用户实机指出米立龙和玛机雅娜的方块模型与整合包主题不符，确认保留用户提供的旧 Pixelmon 模型。之前将形态路线缺失误判为需要整体更换视觉素材，已纠正。

## 本次修改

- 玛机雅娜和米立龙恢复 `Pixelmon-9.13-1.9.jar` 已导入的平滑模型、原骨架、待机／行走动画、普通／闪光贴图与自发光引用。旧资源文件不重绘、不改色、不修改网格。
- 删除被拒绝的 Navas 方块模型、动画和贴图，保留独立来源的像素头像。旧转换脚本入口改为恢复旧资源，避免照历史交接命令执行时再次覆盖。
- 两种玛机雅娜共用玛机雅娜进化石，但普通来源只进入 `mega`、原始颜色来源只进入 `megaoriginal`；分别退回普通和 `original_color`。普通／闪光不用于代替来源颜色。
- 三种米立龙共用米立龙进化石，分别进入 `mega`、`megadroopy`、`megastretchy`，保留各自上弓／下垂／平挺来源；Boss 自身路线不重新抽取其他来源，掉落石头按物种对应。
- 20% 原始颜色自然获取、各种林地府邸结构识别、两项独立成就和忍蛙机制均不修改。

## 外观边界

旧参考包每个物种只有一套 Mega 网格和一对普通／闪光材质。本次按用户决定复用这套旧资源，三种米立龙 Mega 和两种玛机雅娜 Mega 保留独立身份、来源、头像和退化路线，**不再声称它们已具有独立差异网格或完整的原始颜色专用 Mega 配色**。未把闪光材质改名当作原始颜色材质，也未用方块素材填补差异。非 Mega 原始颜色玛机雅娜沿用本体已有原生外观。

## 测试地图

辅助包新增独立的 `mega-gallery.json`，60 个展示位：49 个 ZA 清单条目（含雌雄超能妙喵）、两种未进化玛机雅娜、三种未进化米立龙、小智版 Mega 忍蛙和五个闪光对照。每格间隔 20 格，按名称标记。

旧存档升级时仅清理此命名测试世界中带 `ZaMegaTest` 标签的旧展示实体，不删除正式存档、玩家自行放出的实体或现有队伍。使用版本标记重建一次；下次进入不重复生成。不自动开始战斗。

可重复构建辅助包：`build-mega-test-map.ps1`。隔离实例仍使用 `manual-mega-160-r1` / `backport-mega-160`。

代码检查涵盖五条来源路线、共用进化石、Boss 关联、旧资源哈希、原生 PQC/BMD/动画加载、全部 60 个展示条目、49 个 ZA 清单条目覆盖及未进化原始颜色玛机雅娜。实机外观由用户验收；不将结构检查当作视觉验收。

构建产物 SHA256：`5b6214aa79eb683d367f01d1b4e4500110368c0f2b082d22d32917356f7559e7`。隔离客户端安装的核心哈希相同，辅助包内包含 60 项目录，核心包无已拒绝的方块 BMD／PQC。

测试客户端已进入地图：日志确认 `ZA_MEGA_GALLERY_PASS entries=60`、`ZA_MEGA_NATIVE_PASS forms=16`、`DEN_PLACEMENT_PASS`。这是实际注册／地图初始化检查通过，外观是否满意仍由用户亲自验收。客户端保持开启。

## 展示实体距离清除修复

用户走远后展示被清除。原因是 Minecraft 持久化标记不能代替 Pixelmon 的 `canDespawn` 开关。测试辅助包对全部 60 个带标签展示实体禁用原生距离／计时清除，并在实体重新加入世界时恢复保护。原生 NBT 不保留该 Java 字段，因此重载事件必须补设。独立测试 Boss 的临时等级也按存档标签恢复，避免重载后失去 Boss 身份或退回普通形态。仅对指定测试世界内的展示实体生效，正式包和正常野外刷新不变。地图版本标记升级为 v3，重新生成已丢失的展示，不改队伍。
