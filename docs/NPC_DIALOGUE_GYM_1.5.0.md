# 1.5.0 NPC 对话与馆主道具

## 改动

- 任务对话收到服务器回复后解除点击等待，避免提交失败后选项永久失效。
- 更新当前对话数据时刷新界面，结束任务对话时额外发送原生 CLOSE 动作，解决“再见”仍留在屏幕的问题。
- 等待回复超过 8 秒时允许 Esc 离开；不会自动重发提交、自动推进任务或发放奖励。
- 服务端拒绝不属于当前已登记对话的选项编号，关闭失效界面后可以重新交互。
- 原任务条件、故事文案、物品提交和奖励路径保留。
- 仅道馆主的复活药由 `revive` 换为 `max_revive`。复活仍计入原复活次数；其他 NPC、用药预算、AI 时机和选择目标保持原逻辑。徽章等奖励隔离逻辑不改。
