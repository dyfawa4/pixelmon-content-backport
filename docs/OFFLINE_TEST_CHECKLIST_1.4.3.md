# 1.4.3 人工测试清单

开始前记录构建信息、游戏／Java版本和测试员原有模组是否改动。每项标记通过、失败或未测。

## 1. 启动、退出与重进

- 安装本包两份JAR，主模组只有一份，正常进入功能图与正常新世界。
- 正常保存退出后再次进入同一世界，不卡100%、不反复出现初始选择、不开自动对战。
- 本包两份JAR都有pack.mcmeta，不应因内部巢穴诊断工具弹出“0个警告”页；本包不含该工具。其他模组警告请保留具体内容。

## 2. 太晶与极巨巢穴

- 05功能图检查1／3／6星太晶、原生极巨对照：进入团战、选择招式、胜利、捕捉与奖励。
- 正常新世界检查自然生成的两类巢穴，记录世界种子、群系、维度与各巢穴坐标；不能把同一个巢穴或空巢引导线重复统计。样本不足时只报告所见数量。
- 有首领的太晶巢穴可以挑战；打完变空后，引导线隐藏。空极巨也按探测器原有规则隐藏。刷新出首领后再显示。
- 当日已完成的太晶巢穴正常退出、重进后仍为空，不能靠重进反复刷新。进入下一游戏日后，按原生巢穴刷新时点检查新遭遇；本包未调整原有刷新时间配置。正常新世界不要关闭日夜循环。
- 旧版异常空巢只进行一次兼容恢复，不应每次重进都重新抽取。有玩家参战时不能替换正在打的首领。
- 遭遇按原生极巨巢穴群系分组筛选，新增物种再按真实野外群系／维度或进化家族筛选，空候选不得退回全物种池。
- 轰鸣月仅末地，无极汰那仅主世界沼泽，阿尔宙斯对应山地；智皮卡指戴帽子的皮卡丘，两类巢穴都不能出现。
- 指南针的太晶巢穴搜索按20类群系区分；搜索可完成／失败／取消，游戏与指南针状态均不应永久停住。
- 远距离传送后，不应保留卸载区块或其他世界的失效线段。

## 3. 补给站领取后的引导线

- 正常世界找可领取补给站，领取前显示引导线。当前玩家成功领取、仍不可再次领取时隐藏线，标记和信息保留。
- 原生冷却结束、恢复可领取后恢复线；一次性补给站仍按原有一次性规则。
- 仅点击但未成功领取不能自行记为已领。多人场景中，另一位玩家领过不应使自己的线消失；多人测试双端同步主模组。
- 退出重进和更换维度后状态仍以当前玩家、当前世界为准。

## 4. 玛机雅娜府邸结构刷新

- 在正常世界真实林地府邸内检查原生传说候选查询（通常为`/checkspawns legendary`），不要在功能平台测自然刷新。
- 当前BOP府邸群系：针叶林、垂死树森林、不祥树林、季节性森林、时令果园。它们共用minecraft:mansion登记，具体ID见`docs/MAGEARNA_MANSIONS_1.4.3.md`。
- 非黑森林的真实府邸也能满足结构条件。仍需白天、室内和白桦木板地面；50级、传说间隔和稀有度0.3保持原值。候选权重不是实际刷新成功率，不能要求进去立即出现。
- 不同府邸房间、楼层、朝向及跨越起始区块的区域应按真实片段判断；室内符合原有地面等条件的位置才有资格。
- 在府邸外另搭相同材料的房屋，没有真实府邸记录时不应通过；不要在原府邸结构范围内搭房来做这个反例。

## 5. 忍蛙、汉化与幸运方块

- 02地图“牵绊进化测试”提供蓝色头冠的未变身个体，首发对手1HP且有后备。亲自击倒触发后变为红色头冠、背后蓝色手里剑的小智形态。
- 普通形态飞水手里剑15威力、2～5击；小智形态20威力、固定3击。详情页和对战侧栏一致。
- 小智形态使用飞水手里剑播报强化自身，三回合水系威力提升50%；重复使用刷新时间、不叠加。到期只播报一次。
- 战斗结束、PC存取、正常重进后，已获得的常驻小智个体及UUID保留。使用地图重置会主动替换测试队伍，不用于验证保留。
- 检查NPC中文对白换行、不超框；探测器配置分类、选项与说明中文完整。
- 幸运方块不应抽到MissingNo、乱码占位或未启用预览种类。

## 6. 最新岩石城

- 打开`backport-gym-v143-rock-vanilla`：完整原版沙漠神殿、居中摆放、四周通路、旧黄色地框已移除。
- 原有NPC服务与道馆奖励可用。地下仍有原版压力板／TNT机关，属于地图内容。
- 测试中改坏地图后，可重新从原压缩包取干净副本，不覆盖需要保留的原世界。

## 7. 修订 2：任务书、皮卡丘提示与启动

- 使用现有任务书编辑模式，给“发现结构”填入模组实际注册的结构类型 ID（含命名空间）。在真实结构具体片段内应能完成，片段外和相同材料的自建房不应完成。原版要塞／沉船任务继续可完成；保留原有任务前置条件。
- 进入与野生戴帽子皮卡丘的战斗，提示该宝可梦无法用大师球、公园球和起源球捕捉。同场不反复弹出，普通皮卡丘和忍蛙不提示；原有禁止捕捉规则有效。
- 首次启动、正常退出后再次启动各检查一次；若仍等待，保留窗口并回传日志／线程快照。修订仅移除 Lootr 装饰赞助名单下载，不用删除 Lootr 或重建世界。
