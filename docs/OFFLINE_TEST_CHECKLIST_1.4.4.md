# 1.4.4 人工测试清单

每项记录通过／失败／未测。先核对构建信息与主模组版本，使用独立副本。

## 编辑器中文操作

- 管理员编辑器用中文物种、球种、招式、携带物名称修改，保存后重新打开检查；包含戴帽子的皮卡丘、太晶爆发、高级球和吃剩的东西。
- 中英文前缀 Tab 补全均可用，原英文输入及物品 ID 保留；无效或半截名称不应替换成其他内容。重名招式用附带英文标识的中文补全项区分。
- 未更改的招式保留已有 PP；性格、形态、体型与特性正常。联机无权限玩家仍不能使用编辑器。详见 `docs/EDITOR_CHINESE_2026-10-16.md`。

## 优先：联机传送时的对战

- 房主在究极空间进行太晶团战，另一玩家从主世界 TP 到房主身边；房主不应退出对战或崩溃，能够正常选招并完成战斗、领取奖励。
- 交换房主与客人的角色，分别测普通野生战、训练家战、原生极巨团战与太晶团战；同维度 TP 也应正常。
- 本人跨维度离场按原生处理，不应残留可点击的失效选招界面。原生正常退出、战后升级与学习招式仍应可用。
- 本项目前通过实际本体字节码离线回归；需记录真实联机结果，见 `docs/BATTLE_TELEPORT_CRASH_2026-10-16.md`。

## 1. 开局与「奇装异服」

- 干净世界选择普通水水獭等初始宝可梦，不应获得「奇装异服」或其他不对应物种的外观成就；保存退出后重进也不应误发。
- 获得真实闪光或对应特殊材质仍可正常完成。普通物种不能替代指定物种，正确物种但错误材质也不能完成材质子成就。
- 普通伊布、未知图腾、小陨星保留原生根分支开启规则。伊布家族必须实际获得九种不同成员，重复获得伊布不能集齐；未知图腾、小陨星的各形态按原要求收集。
- 老存档已误发进度不自动撤销，不能仅用该存档已亮起的图标判定新修复失败。

## 2. 神兽取得与变形

- 同行六只满员后捕获神兽，直接进入 PC 就完成对应物种成就，无需取出；正常重进保留。
- 盾首发、苍响候补：本次藏玛然特实际变形只完成「盾之王」，苍响实际换入并变形后才完成「剑之王」；交换首发再验证。
- 两王各自携带正确腐朽道具场外成功变形也可完成；收到现成形态、错误道具或没有发生变化不算亲自变形。
- 普通／伽勒尔三鸟各对应自己的条件；蛋、取消或失败的进化／合体不计完成。

## 3. Z 招式与黄边框

- 对战打开普通 Z 招式选择，物理、特殊和状态招式均不应闪退；普通 Z 不显示黄色边框。
- 只有实际受到爆裂场地作用的招式显示黄边，符合条件的队友普通招式也能受益；智皮卡专属招式仍需实际场地生效。伤害、持续与效果保持既定规则。

## 4. 野外 Boss 禁球

- 各种颜色、等级及新增种类的真实野外 Boss 都不能投任何精灵球，包括大师球、公园球、起源球。
- 已停留在精灵球分类时，再次选择也应被原生提示拒绝，不扣球、不消耗回合；治疗道具可正常使用。
- 普通野生宝可梦仍可正常投球；原生极巨／太晶巢穴的战后捕捉保持原规则。
- 戴帽子皮卡丘的三种球限制及战斗开始提示继续生效，提示末尾保留感叹号。
