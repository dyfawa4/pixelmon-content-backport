# 1.4.1 V1.9.9收尾追加

记录日期：2026-10-14。适用整合包实例“宝可梦：轻快之旅 V1.9.9”。本次纳入1.4.1正式发布。

- 智皮卡神兽查询识别原生翻译后的候选名，补上专属生成率说明：全局70%时为30%，候选权重100%并不代表每次必定刷新。平原真实村庄限制及实际概率规则保留。
- 祠堂译名统一为“栎树林祠堂”。
- 新生成的原生路标建筑中，蓝色基础补给站以30%概率替换绿色罕见、10%替换紫色传说，60%保持蓝色。同步替换原生颜色及奖励表，保留朝向、领取及冷却流程。每个位置只进行稳定的一次选择，玩家摆放和已经生成的站点不重新抽取。
- 任务书打开时发现客户端任务数据未就绪，会向安装新版附加模组的服务器请求重新同步；数据与队伍信息就绪后自动打开。真正缺少相应服务端功能时保留原有提示。同步只发送服务器已有任务与队伍数据，不重新执行登录奖励，不修改任务内容、完成条件或奖励。
- 普通太晶倍率按用户所附原生规则保留：与太晶属性一致的伤害招式本系加成1.5倍；太晶属性同时也是原属性时2倍；其他原属性本系加成保留。
- 成就“殊途同归”：实际获得并拥有牵绊进化特性的甲贺忍蛙才能完成，其他特性不计入；通过同行队伍或PC的真实获得路径触发。
- 小智版甲贺忍蛙使用飞水手里剑时，先获得仅自身的水系伤害50%加成，本次攻击即可受益。持续三回合，包含使用当回合；重复使用只刷新三回合，不叠加。普通甲贺忍蛙无此增益。保留小智版单次威力20、固定3击的原规则，中英文招式描述已同步补充。
- 增益开始、到期结束均在对战回合信息播报；换下会清除增益，对战结束清理临时状态，不修改永久养成数据。

最终Java11编译及本轮离线回归完成，证据见[发布验证记录](VALIDATION_1.4.1.md)；没有运行自动游戏验收。间歇性任务失步的现场原因尚缺V1.9.9日志，当前增加的是针对任务数据未就绪的恢复流程。

安装时关闭游戏，替换实际实例mods内旧的回迁附加模组，只保留一份1.4.1；多人服务端也应同步替换。保留原Pixelmon、FTB模组、任务书数据、配置与存档。
