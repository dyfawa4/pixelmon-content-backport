# 1.2.0 开发要求

记录日期：2026-10-11。1.1.0 已发布，以下工作归入 1.2.0。

原有情况先核对并记录于 [道馆基线清单](GYM_BASELINE_1.2.0.md)。属性道馆数量依据生成注册、馆主队伍/对话与徽章奖励确定，反派基地单独统计，不能用皮肤或目录数量代替。

## 道馆与城市

- 保留原有十种属性道馆，补齐一般、格斗、飞行、毒、虫、岩石、超能力、恶，共十八种属性。
- 全部十八种属性道馆均须对应完整的大城市，包括道路、住宅、商店、宝可梦中心和道馆；不能只增加独立道馆建筑。已有十类也需检查，不仅验收新增八类。
- 新城市具有各自的建筑配色、地标和属性主题，优先检查已有 ZA 定制模组及原版重铸素材，也可调查作者公开的建筑素材。
- 新增八城使用不同街区和建筑轮廓，不能用同一套布局换色充数；城市商人、服务 NPC、训练家、物资和原有功能完整保留。
- 新增城市与原有城市规模一致，保留原有城市的道路、住宅、中心、商店、训练家、装饰和物资设施，不做缩小版；必须接入自然生成，而不只是指令放置。
- 全部十八类道馆均有各自的特色徽章和可获得的馆主胜利奖励；保留原十类徽章，新增八类徽章。新增徽章的中文名称、Shift 用途与获取说明、JEI 查询完整联动。
- 保留旧世界和旧道馆；自然生成的新增城市需要探索新区域。
- 十八种属性道馆各提供一张独立测试地图，包含该属性完整城市、对应馆主及奖励，并提供查看/挑战操作。原有七张功能测试地图继续单独保留。

## 实力相当道馆 NPC

- 只优化道馆内 BossTier 为 equal 的 NPC，不扩大到普通训练家或其他难度。
- 保持原有实力相当的等级规则，不额外提高等级、IV、EV 或伤害倍率。
- 保留合理的原队伍逻辑，增强合法配招、属性覆盖、换人、恢复与变身决策，使其接近熟练玩家。
- 最终追加针对单一克制属性的对战检查，确认有合法的反制配招和防守选择，难度来自战术而非额外数值。
- 在条件和战斗规则允许时合理使用 Z 招式、Mega 进化、极巨化、太晶化及有限的治疗/复活道具；不要求每场必用、不固定出招顺序。
- 王牌物种应有变化；首次生成后队伍、配招和配置保持固定，读档和再次挑战不能重新抽取。
- 变身、携带道具和招式必须满足对应规则。保留此前指定的隐藏配置，不在 README、玩家手册和 Release 更新说明披露其例子、概率或细节。
- 兼容旧版已生成的道馆 NPC，避免覆盖作者或玩家编辑的普通队伍。

## 发布与验证

- 保持独立公开仓库和完整源码，不与重铸百科项目混合。
- 发布说明中的 NPC 项只写“优化实力相当 NPC 的对战逻辑。”
- 验证 Java 11 构建、原生模板池与城市生成、徽章奖励、NPC 固定队伍与合法配招、作用范围、战斗决策、JEI 客户端和无 JEI 服务端。
- 使用隔离测试实例，不操作日常游戏存档；记录实际通过的检查和仍需人工测试的项目。
