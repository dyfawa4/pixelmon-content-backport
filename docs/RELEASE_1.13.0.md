# 重铸内容回迁 1.13.0 完整更新说明

本说明汇总 1.13.0 相对于 1.12.0 的更新。正式版使用已验收的 r11 核心。

适用于 Minecraft 1.16.5、Forge 36.2.42、Java 11 和 Pixelmon 9.1.12～9.1.13。网络协议为 **27**。联机时，客户端与服务端均须替换回迁核心，`mods` 目录只保留一份。单人存档只需替换客户端。包内可选忍蛙增强版本为 1.0.6。

## 下载与安装

下载 **Pixelmon-Backport-1.13.0.zip** 并按照包内说明安装。也可以单独下载核心 JAR。更新前退出游戏并关闭服务端。可选忍蛙增强默认不启用，启用时客户端和服务端须使用相同版本。

本次在 GitHub Release 提供安装包、独立核心、可选增强、完整说明和 SHA-256 校验文件。仓库内公开的构建源码对应 1.11.0。

## 背包、提示与祭坛修复

- 修复溺水维度对战背包内黑暗球被其它球遮住、翻页后出现空行的问题。精灵球排序后重新分配每页行号，点击与显示对应；关闭捕捉概率时恢复原来的顺序。
- 太晶珠物品描述补上句号，移除右键物品时的装备确认窗。太晶珠与三个查询器的首次和重复解锁都在左下角聊天栏提示「已解锁该物品」。已解锁的太晶珠可在装备栏左键启用或停用、右键设置属性。
- 时空祭坛的底座、上部和两侧补齐碰撞及选中范围，随放置朝向旋转。翼部可交互，已有祭坛在区块载入时补齐可用的占位。
- 智皮卡 Z 描述保留野生智皮卡必掉与无序合成两条来源，删去「获取：」及大师球、GS 球的掉落概率文字。

## 究极丛林团战

- 原版重铸 9.1.13 的究极丛林自然极巨巢穴名单没有超梦。普通超梦列在末地五星名单中。回迁的自然太晶巢穴也按生物群系筛选。传说许愿道具可以跨生物群系抽取，普通超梦仍在可抽取名单中。

## 对战与道馆

- 修正「实力相当」AI 反复使用清除浓雾的问题。只有清理场地或降低闪避能带来实际收益时才考虑使用。
- 面对电太晶、神奇守护与气球的组合，AI 按实际伤害预览寻找能造成伤害或施加持续伤害的队友，同时判断换入是否合法、能否安全出场。作者道馆对手存在神奇守护且队伍缺少持续伤害手段时，按原技能池和可用槽位补充剧毒、鬼火或寄生种子，优先保留原有反制、本系招式、先制招式、强化和辅助招式。
- 修正双倍奉还、镜面反射、金属爆炸与同命的决策，按伤害类别、免疫、先后手和生效时点判断。被困且攻击会导致致命反伤或同命时，可选用现有合法辅助招式。能够直接击倒对手时仍会评估进攻。
- 核对踩影、黑色目光和雷电囚笼的换人限制。幽灵属性、蜕壳、换人招式及困住来源离场等情况按原生规则处理。
- 作者道馆第二次及以后挑战新增禁用百变怪、梦幻和图图犬。首次有效胜利后启用再战规则，旧存档中的首次胜利也计入。[作者道馆再挑战规则](https://github.com/dyfawa4/pixelmon-content-backport/blob/v1.13.0/docs/作者道馆再挑战规则.md)
- 修正传送后首次挑战以及再次挑战时的馆主音乐。覆盖 18 种属性道馆，普通馆主播放《宝可梦 Let's Go! 皮卡丘／伊布》版本，作者道馆使用自己的曲目。PixelTweaks 的阿尔宙斯专属曲只在遭遇野生阿尔宙斯时播放。
- 诅咒甲贺忍蛙 Mega 退场后恢复原材质，覆盖换下、战斗结束和场外恢复。
- 溺水 Boss 的祸提示改为「仅治疗后可以清除」，沿用现有治疗判定。

## 太晶化与巢穴

- 太晶按钮放在原生招式页中央圆圈，默认显示统一晶体图标，选中后切换对应属性图标。按钮读取服务端装备状态，修正与原生图标重叠及已装备太晶珠却无按钮的问题。只有太晶珠时也能装备和使用。修复部分野战中原生图标留在中央、导致已装备且有充能的太晶珠无法操作的问题。
- 太晶化持续到宝可梦濒死或对战结束。换下再上场时同步新实体的太晶材质和冠饰，并保留属性相性、本系加成和太晶爆发的属性转换。隔离战斗经过 85 次回合结算和 3,700 个游戏刻，未复现长局中太晶化消失。
- 核对五星极巨巢穴和太晶巢穴在开战时变身。护盾实测中，极巨盾拦下普通攻击和极巨招式的 HP 伤害，两者分别破一格和两格盾。太晶盾在未太晶、太晶后使用异属性招式、太晶后使用同属性招式时，分别保留 20%、35%、75% 的伤害。
- 极巨和太晶巢穴生成传说宝可梦时排除指定特殊材质，保留原有常规外观与异色规则。

## 查询器、捕捉与能力页

- 个体值、努力值查询器各自可右键消耗并永久解锁。启用时，在原生能力页六项属性的对应位置显示数据，沿用原版字体与渲染方式，个体值栏目也显示王冠强化后的数值。
- 新增捕捉概率查询器，采用原创贴图及立体手持模型，并调整了第一人称比例。右键消耗后永久解锁野战背包和巢穴结算里的捕捉概率。
- 三个查询器均显示在装备栏。未解锁时显示锁标记和解锁提示，解锁后可分别左键启用或停用。关闭栏目后恢复原界面。重复使用已解锁的查询器时保留道具，聊天框提示「已解锁该物品」。已有的永久解锁状态会随存档保留。太晶珠和三个查询器的使用提示显示在左下角聊天栏。装备栏滚动到底时保留足够的空间，显示完整的最后一个护符。
- 概率显示支持野战、极巨及太晶巢穴，并按各自捕捉规则处理会心捕捉、爆裂场地、禁止捕捉和大师球限制。启用显示时精灵球按实际概率从高到低排序，同概率保留原有相对顺序，关闭后恢复原排序。
- 智皮卡生成提示和图鉴说明补充「不享受爆裂场地的抓捕加成」。

## 进化、招式与宝可梦编辑器

- 「真龙点睛」使用更新后的简体中文名称。具备资格的烈空坐忘掉该招式后，可在原生招式回忆者处学回。旧存档会补全回忆资格，普通烈空坐照常回忆「画龙点睛」。
- 退化时清除进化形态专属招式，重新进化后按实际分支走原生招式学习流程。旧存档进入世界时自动检查玩家的同行与 PC，清理招式栏及回忆记录中因退化或跨分支进化遗留的非法招式。招式回忆界面与服务端学习共用限制。已覆盖两种武道熊师、科斯莫古、无畏小子等家族，连击流武道熊师可保留合法的水流连打。
- 进化页显示酋雷姆、奈克洛兹玛、蕾冠王的融合双方与所需道具。融合双方都能查看，奈克洛兹玛页还列出后续究极爆发条件。
- 宝可梦编辑器开放已登记的创作者等特殊配色并补齐中文名称。无极汰那的无极巨化与异色无极巨化统一沿用重铸内置的形态、模型与配色。
- 移除代欧奇希斯的 Deoxsus 选项，旧个体载入时转为防御形态。陨石仍在四种标准形态间切换。

## 世界、任务、NPC 与物品

- 用 GS 球重置已使用的栎树林祠堂，用天界之笛重置时空祭坛，用对应充满的珠子重置三圣鸟圣坛。生存模式成功重置时消耗对应道具，并在聊天框提示。重置后可再次召唤。
- 成熟树果按生长节奏随机掉落，树叶随后可重新长出果实。人工采摘仍获得经验，腐烂时按原有方式掉落一次。
- 原生村民任务中，灰烬、诅咒、雷霆、溺水和异色目标补充对应地点或时段提示。
- 移除邮件店员和 NPC 编辑器中的「邮件」类型。旧存档已存在的邮件店员在所在区块载入时移除。NPC 编辑器切换店员类型后立即重建货架，重新载入仍保留新商品。NPC 创建菜单移除 TCG Trader。
- 新增老渔夫召唤器，使用带钓竿纹样的绿封面书。召出的老渔夫固定站位、不会自然消失、无法命名，可被生存玩家攻击，鉴定钓竿免费。召唤出的招式回忆者及老渔夫，在正常方块交互距离内可被对准和攻击，仍受方块遮挡。
- 搬家协议配方只接受原生确有球盖的球种，移除 GS 球盖等无效选项。
- 修复创造背包中键复制普通物品，数字键替换仍保护受保护的快捷栏物品。在创造分类和搜索中隐藏六种努力值羽毛、美丽之羽、空白邮件与密封邮件。
- 紫色名称用于两个奈克洛合体器及除智皮卡 Z 外的其他专属 Z。金色用于金色王冠和智皮卡 Z。蓝色用于海声铃铛、寒冽珠，橙色用于透明铃铛，红色用于红色锁链、虹色之羽。非专属 Z 沿用原有颜色。
- 修正引导线问答按钮的文字重影。

## 稳定性

- 修复普通巢穴刷新时无效物种或形态导致的崩溃，覆盖生成、写入和读取存档。
- 修复与 ModernFix 共存时，结构模板加载失败后重试可能持续等待的问题。已在隔离环境复现旧行为并验证新版能重试和读取村庄模板。
- 修复玩家区块票据重复移除时的空指针，覆盖玩家落入虚空后退出旧区块的路径。
- 深层动力铁轨的更新交给原生计划刻继续处理，避免递归层级过深导致栈溢出，浅层更新照常即时执行。
- 隔离测试覆盖了已定位的故障路径。ModernFix 缓存问题仍需实际服务器存档复测。

## 原版重铸的旭日与满月状态

Pixelmon 9.1.13 内置索尔迦雷欧的 `radiantsun` 和露奈雅拉的 `fullmoon`。两种形态都复用基础模型，各有普通与异色的材质和图标。属性、种族值、特性和招式沿用基础形态。

该版本中，科斯莫姆在白天或夜晚达到 53 级，分别进化为基础形态的索尔迦雷欧或露奈雅拉。本地数据未找到旭日与满月的生存获取入口，专属招式也没有切换形态的配置。管理员可用 `form:radiantsun` 或 `form:fullmoon` 查看。

《宝可梦 太阳／月亮》将两者描述为释放力量时的发光姿态。[《宝可梦 太阳／月亮》官方网站](https://www.pokemon.co.jp/ex/sun_moon/story/160701_02.html) · [Pixelmon 官方形态表](https://pixelmonmod.com/wiki/Form_indices)

## 发布验证

r11 在 Pixelmon 9.1.13 的隔离客户端通过 57 项检查。正式发布沿用同一份核心 JAR。验证包括溺水维度背包翻页与选球、太晶珠和查询器提示、时空祭坛碰撞及旧祭坛占位恢复。
