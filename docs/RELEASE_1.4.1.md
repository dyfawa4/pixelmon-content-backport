# 重铸内容回迁 1.4.1

发布日期：2026-10-14。适用 Minecraft 1.16.5、Forge 36.2.42、Java 11，以及已验证的旧版 Pixelmon 重铸本体（文件名9.1.13、内部版本9.1.12）。这是独立附加补丁，不附带重铸本体或完整整合包。

## 甲贺忍蛙技能更新

完成牵绊进化、保有Battle Bond特性的小智版甲贺忍蛙使出飞水手里剑时，**先获得仅自身的水系攻击威力50%增益，再进行本次攻击**。当前攻击立即受益，持续三回合，包含使用当回合。重复使用只刷新三回合，倍率不叠加；其他自身水系伤害招式也可受益，队友不共享。普通甲贺忍蛙不变。

保留小智版飞水手里剑原有单次基础威力20、固定3击：增益期间每击按30计算，三击基础威力合计90，并继续经过正常伤害公式。第1回合使用后，第1、2、3回合有效，第3回合结束播报到期；第2回合再次使用则延长到第4回合结束，仍是1.5倍。换下、倒下及对战结束清理状态，不写入永久养成属性。

增益开始、到期及换下清除均有回合信息，中英文技能描述同步更新。原生小智形态与本模组常驻小智形态均支持，Mega形态不因此取得小智强化。

新增成就**「殊途同归」**：实际获得并拥有牵绊进化特性的甲贺忍蛙，真实存入同行队伍或PC后触发。其他特性无法完成；此成就不要求先变成小智形态。

完整条件、数值和计时示例见[忍蛙专项说明](GRENINJA_1.4.1.md)。

## 智皮卡与生成修复

- 修复平原真实村庄中智皮卡的生成与神兽查询漏判，包括村庄跨区块范围。
- 查询区分全局神兽概率、候选权重及智皮卡专属概率。全局70%时，智皮卡规则为减40个百分点后的30%；候选权重100%不代表必定刷新。
- 智皮卡固定为公，旧存储中的雌性独立智皮卡会校正；保留UUID、养成、闪光、招式和携带物。
- 可正常产生战利品的野生智皮卡被击败后，战利品保证含大师球1个和智皮卡Z1个。捕捉、逃跑、玩家或NPC拥有的个体不发这项奖励。
- 原生极巨化及太晶巢穴单独排除智皮卡，唯一自然刷新渠道仍是平原真实村庄。70级、捕获率3及已有禁球规则保留。
- 智皮卡Z移除冲突的原生旧描述，保留当前专属玩法说明。详细规则见[智皮卡与Z说明](CAP_PIKACHU_1.4.1.md)。

## 其他修复与改进

- 修复点击多人游戏触发递归并崩溃的问题，保留自存服务器、直接连接和局域网入口。
- 探险家指南针和自然罗盘补齐中文界面、结构、群系及维度显示；祠堂名称统一为「栎树林祠堂」。
- 检查全部Mega Boss头像，将ZA新增的模型截图头像替换为原生尺寸的像素图，覆盖普通与闪光。复用现成素材，归属及许可见[第三方资源说明](../THIRD_PARTY.md)。
- 新增Mega烈空坐成就**「凌云九霄」**：自己的烈空坐在场外或对战内成功完成Mega进化后触发，失败、取消、NPC或直接获得Mega形态不算。
- 新生成的基础蓝色补给站，30%替换绿色罕见、10%替换紫色传说，剩余60%保留蓝色；三种结果互斥。保留原生奖励与领取流程，不对玩家放置或既有站点反复抽奖。
- 任务界面因客户端任务数据未就绪无法打开时，增加服务端重新同步及就绪后自动打开流程。服务器任务、进度、条件和奖励不作重置；真正缺少服务端功能时仍保留原生提示。
- 复核普通太晶本系规则：招式与太晶属性一致为1.5倍；同时属于原属性为2倍；其他原属性的本系加成保留。没有改成太晶前伤害额外乘1.5。

任务书内容、目标、奖励与条件均未修改。
