# 太晶化外观回迁验证（r10）

2026-10-17。当前 r10 保持薄结晶表层，扩大局部属性色反射，收窄白色高光中心，以改善 r9 属性区分过轻的问题。冠冕沿用此前基本通过的挂载。r8 的整体颜色过深已被用户否定，不能将其写成最终验收通过。全部物种、形态及多人环境仍需验收。

## 基线与来源

1.4.5 基于已发布 v1.4.4 提交 `5bf775fb234cfbad39bd6f7bb0c19de204d36bfb`，未发布新 Release。原 NPC 文案和已经验收的 NPC 离线包不改。

冠冕为官方 Pixelmon 1.21.1 9.4.1 的完整 19 属性模型及原 PNG，来源、哈希见 `resources/backport/tera_visual_sources.json`。材质进一步参考同版本 `terrastalization.*`、`stellar.*` 的逐面反射、闪烁和边缘反光，以及朱／紫官网外观说明；参考资源链接及六份文件哈希见 `resources/backport/tera_material_reference.json`。高版本保留原皮肤并增加晶面反光，不是整身涂纯色。旧版以固定管线适配实现，没有打包高版本 Java 类或无法直接运行的 ShaderInstance。

## 本轮修复

- 相对 PQC `$body` 被旧加载器强制解析为 pixelmon 命名空间。改为完整 pixelmon_backport 引用，并调用真实 ValveStudioModel.getResource 回归。
- 原生 Bone.applyModified 在蒙皮后立即 reset。现在在 reset 前保存实际头部姿态，在对应模型绘制时读取，不再读重置后的单位矩阵。
- 旧骨骼矩阵与 Minecraft 字段布局不同。复制并转置，保留完整旋转和位移；不修改原生矩阵。新增 1000 组真实蒙皮／渲染矩阵对照。
- 通用落点使用头部中央射线与实际皮肤的交点，避免耳朵、角尖抬高底座。无头骨的模型跟随当前动画网格表面，附件大小保持稳定。帽皮正常／异色均有旧坐标 [0,1,-21.2] 的帽顶配置，只缩放冠冕。
- 原 SMD transparent 是加色发光，会洗掉身体原色；UV 晶体图案也会拉成脖子／翅膀条纹。改用普通透明混合、同表面深度判定和实际动画三角面的稳定明暗、闪烁及边缘反光。身体顶点、动画和体型不变。
- r8 减少白色高光，提高属性色饱和度和表层可见度。保留窄高光、晶面棱角及底层原色／异色特征，观感仍需实测反馈。
- 变身调用原生进化／Mega 光束，临时客户端渲染字段在 finally 恢复；不发进化包，不调用 updateSize 或极巨化缩放。

## 同步和测试范围

临时实体元数据由真实战斗名册中的存活、上场成员驱动，排除模拟和 AI 克隆，由原版实体追踪同步附近玩家及后加入者。变身开始 tick 服务端同步，过期不重播。同步协议为 **10**，两端需一起更新，不把活动太晶状态保存进宝可梦 NBT。

皮肤透明边界保留；动态贴图缓存最多 64 项，冠冕最多 19 项，在帧间／重载／退出清理。普通非太晶实体不建渲染上下文，环境粒子限制在 32 格内。厄诡椪、太乐巴戈斯保留专属形态。

独立图鉴仅打包在测试辅助模组，F8 或 `/terapreview`、`/太晶预览` 打开。支持全部注册物种／形态、中文英文编号搜索、正常异色、19 属性、原型对照、旋转缩放、动画、光束及截图。临时对象不加入世界、队伍或战斗；主补丁不含 TeraVisualPreviewScreen。场地入口和实战区均有控制台，战斗结束返回入口。

## r9 清透材质修正

用户确认「现在太深了，按你说的来」。本轮不改冠冕、骨骼挂载、身体几何或缩放，仅修正身体材质：

- 移除 r8 大面积属性色染色与随机深浅涂块。普通表面只保留很薄的透明结晶层；原皮肤及异色作为主体。
- 属性色集中于掠视边缘，镜面高光使用带少量属性色的明亮反射，不把整只身体刷成白色。
- 反射光随时间移动并响应当前动画三角面的方向，稳定晶面相位形成局部闪光；没有 UV 拉伸条纹，没有扩大网格。
- 非 SMD 兜底表层强度也同步降低。独立图鉴及 19 属性切换保留，窗口标记 r9。
- 新增真实顶点适配器检查：代表性的非反光表面透明覆盖低于 12%，保留至少 88% 原色；窄镜面反射可见；移动光源改变反射；水属性在掠视边缘保持明确的冷色。此数值是测试样本，不是所有视角的统一透明度承诺。

## r10 属性反射与后台实测

用户要求弥补属性区分轻的问题并后台查看各属性。本轮只改身体材质：采用独立的反射色表，扩大局部彩色反射的肩部范围，保留更窄的白色高光中心；普通面仍是薄透明层。没有更改 UI／团体战属性色、原皮肤、异色、身体顶点、冠冕定位或缩放。

在两个独立的完整整合包测试实例中，分别加载保存的 r9 主 JAR 和 r10 主 JAR，使用相同动作、帧时刻、性别及视角，通过实际 Minecraft 图鉴渲染截图：

- 6 组：普通／异色喷火龙、普通／异色自制帽皮、阿罗拉九尾、月亮伊布。
- 每组 19 属性的 40 度视角，另加水／电／幽灵／妖精的 110 度视角；每版 138 张，两版共 276 张，截图任务全部完成、错误 0。
- 已目测六张全属性对照表，并查看第二视角的代表组合。水蓝、电黄、幽灵紫等在局部反光中更明显；一般／钢等近色属性仍较含蓄。反光依赖视角，不承诺任意角度都等强。
