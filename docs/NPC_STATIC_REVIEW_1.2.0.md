# 馆主逻辑最终静态复查

日期：2026-10-11。在城市、场外界面和快龙石改动完成后进行源码复查，不启动游戏，不把源码分支存在当作完整实玩通过。

| 项目 | 核对的代码与约束 | 人工验收重点 |
| --- | --- | --- |
| 作用范围 | `NpcGimmicks.enabled` 同时要求 equal 阶级与属性道馆身份；禁用、普通 NPC 和非 equal 馆主不增强；团战/模拟不生成新配置 | 普通训练家行为是否保持 |
| 队伍固定 | `BackportNpcRoster`、`BackportNpcProfile`、`BackportNpcMovesVersion` 防止重复抽取；新王牌复制已有等级与 IV/EV；已保存配招不覆盖 | 重进与再挑战是否同队 |
| 合法配招 | `NpcMoves` 从该形态原生合法招式池选择，具备本系输出、覆盖与恢复/强化角色；候选物种与配置有变化；开发清单特殊王牌保留完整配招和必需道具 | 实际招式、形态、携带物一致 |
| 观察信息 | `NpcTactics` 使用原生 TacticalAI 对对手的观察记忆和猜测；模拟开关使用 finally 还原 | 未使用的对手招式不应被当作已知 |
| 技能选择 | 危险强化、满血恢复与无后备的转场技能降低倾向；不复活失败/免疫选择，保留优先击倒；低血量恢复须能买到回合 | 不能连续强化送掉、无效回血 |
| 换人 | 保留原生 AdvancedAI 的攻击/换人比较；原生预演后恢复上场与本回合行动标志，避免预演影响真实行动 | 属性劣势时转场、换人后正常行动 |
| 药品 | 每战有限治疗/复活量，正常耗回合；避免能先击倒时用药、无收益回复、模拟消耗或同回合重复计划；按原生事件成功结果扣除 | 实际效果、回合消耗与次数 |
| 四种机制 | `NpcGimmicks.decide/apply` 核对 Mega、Z、太晶、极巨分支；根据已观察压力与收益选择，遵守世代、携带物、饰品、次数与排队状态；用药不同时出招或变身 | 四机制实际显示/执行及失败分支 |
| 克制属性 | 防御太晶、覆盖招式、多种王牌与换人提供反制；不靠额外抬高等级/IV/EV，不能凭源码保证每一种克制队伍都无法轻松通关 | 十八馆完整对战，单一克制策略与综合队伍比较 |

静态检查已完成，当前构建通过 Java 11 编译与离线 Mixin/ASM 校验。此前隔离服务端的决策夹具记录保存在 `VALIDATION_1.2.0.md`；最终对战难度、动画、同步、地图观感与完整流程由用户继续测试；用户已授权本轮完成后直接发布。
