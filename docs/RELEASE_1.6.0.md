# 1.6.0：战斗规则重构、忍蛙专属机制与 ZA Mega 补全

本次是从 1.5.0 升级的大版本，原计划 1.5.1 的全部修复已合并，不再单独发布 1.5.1。重点包括战斗计算与状态处理重构、小智甲贺忍蛙完整强化、ZA Mega 形态与进化石补全、游戏内中文配置恢复，以及太晶巢穴和崩溃修复。

## 一、小智甲贺忍蛙：本次完整规则

游戏内招式介绍为了版面只保留简述，以下是完整效果。**这些强化与“忍者的修养”属于本模组自定义玩法，不是宝可梦官方招式效果。**普通、尚未完成羁绊变身的甲贺忍蛙不获得这些专属加成。

### 1. 飞水手里剑：固定三击，基础 PP 5

| 项目 | 小智形态规则 |
| --- | --- |
| 连续命中次数 | 固定 **3 击**；PP 5 不代表攻击 5 次 |
| 每击基础威力 | **20** |
| 基础 PP | **5**；PP 提升按原生规则最高可达 8 |
| 自身强化 | 使用前获得水属性攻击威力 **×1.5**，即提升 50% |
| 强化持续 | **5 回合，包含使用当回合** |
| 再次使用 | 刷新持续时间，不把 50% 加成多次叠乘 |
| 对手效果 | 在伤害计算前附着独立负面效果 **“蚀”** |

强化会惠及该忍蛙自身其他水属性伤害招式，不会给队友提供加成。每击 20 在强化下按 30 威力参与结算，三击合计基础威力相当于 90；最终伤害还受双方能力、相性、道具及其他规则影响。未命中、保护、免疫、濒死等仍经过原生逐击结算，不保证每次都造成三段实际伤害。自身水系强化换下时清除，倒下或战斗结束也清理。

普通飞水手里剑的共享招式定义没有被全局改成 PP 5，也没有全局固定为三击。小智形态、永久小智形态，以及由小智来源继续 Mega 的形态保留专属资格，**不再单凭当前特性判断资格**。

### 2. “蚀”：六项种族值各减 20，合计减 120

- 降低目标的 **HP、攻击、防御、特攻、特防、速度六项种族值，每项各 20**；单项最低为 1。这不是六项最终能力值直接各减 20，也不是能力等级下降。
- 按降低后的种族值，结合目标当前等级、个体值、努力值与性格重新计算能力；原有能力等级等战斗修正继续参与后续计算。
- **攻击前生效，并立即重新计算对方能力与 HP 上限，本次飞水手里剑即可受益。**重新计算不会额外推进回合或扣除持续时间。
- 持续 **5 回合，包含施加当回合**；重复施加只刷新时间，不能叠成每项减 40、减 60。
- 可以和其他负面效果共存，不占原有主要异常状态的位置。界面采用蓝色标记，只显示“蚀”，不额外挤入名字和回合数。
- 目标换下后仍保留，并按正常战斗回合继续计时；不是换下立即解除，也不是换下就冻结时间。
- HP 上限发生变化时，当前 HP **立即按原血量比例调整**；效果结束后再按比例恢复至正常上限，不凭空回满血。濒死仍保持濒死。
- 战斗结束清理临时效果，不永久改动宝可梦存档中的种族、养成能力或个体值。

例如，某一项原种族值为 100，受到“蚀”后按 80 参与能力计算；原种族值为 15 则按 1 计算。HP 上限由 400 变为 360 时，原本 200 HP 会按比例变为 180 HP，之后再结算本次攻击伤害。

### 3. 新专属招式：忍者的修养

**一般属性、变化招式，基础 PP 5。**使用后大幅提高自身特攻，即 **特攻 +2 级**，随后获得一次额外行动。

- 从 0 级开始，连续强化三次达到 **+6 级**；不是上限 +3 级，也不是无限叠加。受到能力下降等影响时继续使用原生能力等级规则。
- **追加行动中不能再次使用“忍者的修养”**，避免用该招式连续套出追加行动。
- 追加行动仅属于这一只忍蛙。单打、双打、团体战中，队友和对手都不会因此多行动一次。
- 对忍蛙自身来说按一个正常的个人回合结算：自身的持续效果、异常、道具／特性相关回合效果、水系强化计时、极巨化剩余回合等继续走。
- 对手、双打队友、后备队友的计时不额外推进；**对方身上的“蚀”也不因忍蛙追加行动多扣一回合**。天气、场地等共享剩余时间不额外缩短，但天气／场地对忍蛙本人的回合效果仍正常结算。

例如，对方身上的“蚀”剩余 4 回合，忍蛙使用修养后额外行动一次，不会因此将对方的“蚀”扣到 3 回合；忍蛙自己的既有水系强化、极巨化等个人计时则照常推进。之后整场正常回合结束，再照通常规则结算。

### 4. 学习、回忆与 Mega 衔接

普通羁绊变身个体在真实战斗中完成变身后，战斗结束可直接收到学习提示；已经是永久小智形态的个体同样可以学习。如果当时没有学，之后可找技能回忆师重学。

修复回忆师空列表，以及小智忍蛙无法回忆太晶爆发的问题。小智来源继续 Mega 后，即使特性发生变化，强化飞水手里剑与“忍者的修养”的资格仍保留；普通 Mega 忍蛙不会因此误获小智专属强化。结束变形后保持正确的来源身份。

详细独立说明见 [忍蛙 1.6.0 玩法](https://github.com/dyfawa4/pixelmon-content-backport/blob/main/docs/GRENINJA_1.6.0.md)。

## 二、战斗逻辑重构与修复

将基础伤害、群攻、天气、要害、随机、STAB 与属性倍率拆分处理，修正确认的阶段顺序和取整偏差，保留原生道具回调和团体战伤害事件入口。

- 修复毒傀儡识别施毒来源错误。
- 精神噪音与回复封锁按正确目标生效，避免影响其他宝可梦。
- 修正晶光星群／太晶爆发的物理、特殊分类比较。
- 修复星晶太晶爆发在保护、免疫或未命中等情况下错误降低能力。
- 补齐密探斗篷对相关追加效果的阻挡。
- 修正太晶威力下限、太晶甲壳与破格交互。
- 修正万能伞与古代活性的天气判断，以及太乐巴戈斯战斗中变身的 HP 处理。
- 隔离 AI 模拟副本，避免模拟选招改变真实形态、消耗太晶珠或清除真实天气。
- 修复太晶同步遇到自由者／变幻自如改变为单属性时的空槽空指针，涵盖闪焰王牌自由者相关崩溃。

本次校正针对已确认问题，保留忍蛙等既定自定义规则；不代表全部世代、特性组合和多人战斗已经做到与卡带完全一致。

## 三、ZA Mega、进化石与外观补全

补入此前素材缺失的 **16 组 Mega 主体模型和对应进化石**：风铃铃、阿勃梭鲁 Z、姆克鹰、烈咬陆鲨 Z、路卡利欧 Z、席多蓝恩、泥偶巨人、超能妙喵、好胜毛蟹、具甲武者、玛机雅娜、捷拉奥拉、狠辣椒、晶光花、米立龙、戟脊龙。形态目录共核对 49 个 ZA 条目，包含来源及性别变体。

- 接入对应野外 Mega Boss 刷新与进化石掉落；Boss 使用匹配头像，沿用禁止捕捉规则。旧 Mega 与 Z 形态分别对应自己的石，不会串掉落或随机变成兄弟形态。
- 三种米立龙共用米立龙进化石；普通／原始颜色玛机雅娜共用玛机雅娜进化石。进化保留来源形态，还原时回到对应原形态。
- 接入 Mega 种族值和特性数据，并纠正参考包中的七项种族值错误；不是只切换模型。官方图鉴未公开的特性仍采用兼容值，全部 Mega 的每一种运行时能力／变形组合尚未穷举验收。
- 保留与重铸匹配的平滑模型。米立龙变体通过对应主鱼位置区分；原始颜色 Mega 玛机雅娜补银白齿轮及裙摆下部，保留红金主体。
- 改善 Mega 忍蛙水手里剑的比例、厚度和明暗，修复相关材质与编辑器形态显示问题。
- 新增石图标统一原生像素比例与留白；**全体原版和回迁 Mega 石（含 X／Y／Z、共用石）统一 Shift 与 JEI 说明**，使用“让××携带后，可进行超级进化。”，不再显示生硬的名称箭头。
- 补齐基格尔德 Mega 专属“归无之光”：龙属性特殊招式，威力 200、基础 PP 10、非接触光束；处理妖精免疫交互及核心惩罚的临时转换，结束后恢复原招式并正确扣回 PP。

详见 [ZA 补全记录](https://github.com/dyfawa4/pixelmon-content-backport/blob/main/docs/ZA_MEGA_COVERAGE_1.6.0.md)。

## 四、太晶巢穴与巢穴生成器

- **太晶巢穴只允许太晶化**，关闭 Mega、极巨化、究极爆发和 Z 招式入口，并清理残留选招标记，修复误点极巨化后技能变为极巨技能的问题。普通极巨巢穴保持原规则。
- 太晶巢穴只有存在有效、可挑战的遭遇时，才显示光柱及探测器引导线；未生成、空巢或正在占用时隐藏。
- 极巨巢穴生成器、太晶巢穴生成器均可在生存模式使用：**成功放置消耗 1 个，失败不消耗；创造模式可重复使用**。

## 五、中文配置与稳定性

- 恢复游戏内 **P 键**及模组配置入口，中文显示通用设置，支持中文搜索、开关／枚举切换、数字与文字输入。
- 保留输入校验、保存持久化与房主／管理员权限。回迁内容适配通用配置流程，不把每个特殊宝可梦的专属参数堆成额外页面。
- 修复化石复活机偶发显示卡在 **33%**，但实际已完成并能领取的问题；补齐进度与阶段切换同步，不改复活时长与结果，无需拆掉机器重放。
- 禁球提示“小智版皮卡丘”统一改为“戴帽子的皮卡丘”。
- 修复编辑器导入对象脱离存储位置时的异常分支。

## 六、获取与成就

- 林地府邸自然生成的玛机雅娜中，**20% 为原始颜色、80% 为普通颜色**，总遭遇权重不变；按实际府邸结构判断，适配相应模组群系中的府邸，不限黑森林。
- 原始颜色玛机雅娜新增成就 **“闭月羞花”**；普通颜色仍为 **“沉鱼落雁”**，分别记录，支持旧存档登录补查。
- 任务书已有的 12 项神兽特殊材质任务增加同名成就：天外来客、万籁俱寂、美若天仙、幽魂观音、幽魂追风、幽魂捧月、山摇地动、天打雷劈、今天来过平安夜、今天来过圣诞节、五彩缤纷、虹销雨霁。仅对自己真实持有的对应个体授予，蛋及不符任务限制的闪光个体不计；不会代替 FTB 拍照任务或重复发放任务奖励。

## 下载与升级

正式实例只需安装 `pixelmon-content-backport-1.16.5-1.6.0.jar`；功能 ZIP 另附完整手册、忍蛙详细说明与更新记录。测试地图／辅助模组为可选项，正式存档不需要安装。

1. 保持 Minecraft **1.16.5**、Forge **36.2.42**、**Java 11** 及已支持的旧版 Pixelmon 本体环境。
2. 退出游戏和服务器，备份存档；移除旧回迁 JAR，只保留一份 1.6.0。
3. 客户端与服务器同时更新：太晶网络协议为 **12**，不可与旧回迁版本混用。
4. 不包含 Minecraft／Pixelmon 本体、完整定制模组、账号或玩家进度。测试辅助模组仅用于独立测试实例。

发布前完整离线回归、原生 Mixin 转换与专项检查通过；忍蛙实战和数值、相关 Mega 外观由用户人工验收。未执行多人实机穷举。详见 [验证范围](https://github.com/dyfawa4/pixelmon-content-backport/blob/main/docs/VALIDATION_1.6.0.md)。
