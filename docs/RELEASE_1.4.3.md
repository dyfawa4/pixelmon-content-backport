# 重铸内容回迁 1.4.3

发布日期：2026-10-15。适用Minecraft 1.16.5、Forge 36.2.42、Java 11，以及已验证的Pixelmon本体（文件名9.1.13、内部9.1.12）。这是独立附加模组，不包含本体或完整整合包。

## 太晶巢穴与引导线

- 修复新巢穴合法遭遇在群系复核时被清空、全部显示无法挑战的问题。保留群系、维度、形态及智皮卡排除规则。
- 空太晶巢穴与原生空极巨巢穴一样隐藏引导线，刷新出宝可梦后恢复。空巢不再统一提示已经完成挑战。
- 补给站已由当前玩家领取、尚不可再次领取时隐藏引导线，冷却结束后恢复；其他玩家的领取不影响自己的显示。保留补给站标记和信息。
- 旧版异常空巢升级后仅尝试恢复一次；新版已完成巢穴不会通过反复重进刷新。
- 自然巢穴分流仍各50%。主世界独立160万次生产方法抽样为太晶50.038%、极巨49.962%；这是分流算法检查，不冒充自然地图大规模普查。沿线感到太晶更多的一项明确原因为旧版空巢显示口径不同。

## 玛机雅娜府邸刷新

- 将玛机雅娜原生野外刷新条件从黑森林群系改为真实林地府邸结构。超多生物群系中的同类府邸也可满足，玩家自建房屋不会因外观或材料相似而被识别。
- 保留白天、室内、白桦木板地面、50级、传说刷新计时和稀有度0.3。使用跨区块结构引用与实际片段范围，不只检查府邸起始区块。
- 已核对当前Biomes O' Plenty 13.1.0.488的80个群系模板，5个府邸群系均注册并沿用`minecraft:mansion`；详见[府邸兼容检查](MAGEARNA_MANSIONS_1.4.3.md)。

## 小智忍蛙、测试点和幸运方块

- 小智忍蛙的飞水手里剑详情页、对战侧栏统一显示每击基础威力20；固定3击，临时水系强化单独说明。普通形态维持15。
- 强化开始和结束有中英文播报；修复AI模拟副本共用控制器导致结束连续播报三次。
- 手动牵绊测试点提供未变身的普通外观忍蛙，以及首发1HP、真实后备的训练家；保留已取得个体的测试进度。
- 幸运方块随机候选排除MissingNo、未启用预览和无效种类，保留普通／究极异兽／传说分类。

## 岩石城市与地图

- 岩石城中央使用Minecraft 1.16.5原版沙漠神殿，保留双塔、入口、阶梯屋顶和地下四宝箱／压力板／九个TNT。
- 两种广场均为35×35，主体居中、四周留7格，清除旧黄色地框，保留原有服务、奖励及道路连接数据。
- 城市地图包直接包含用户已验收满意的97片段岩石城快照，名称为**回迁道馆 1.4.3 岩石城已验收布局 [rock]**，文件夹`backport-gym-v143-rock-vanilla`。进入即可看到该布局，不重新随机组装。
- 快照只包含城市地形、就绪标记与干净世界设置，不含玩家队伍、账户、玩家存档、FTB团队／任务进度。已有城市不会自动改建。

## 安装与验证

- FTB“发现结构”任务保留原版检测，并补充真实模组结构类型注册 ID 的检测，核对实际结构片段、跨区块引用以及回迁主题。任务书配置、前置、奖励和玩家进度沿用原值。
- 进入与野生戴帽子皮卡丘的战斗时提示：“该宝可梦无法用大师球、公园球和起源球捕捉！”每位玩家同场仅提示一次，原有三种球的禁止捕捉规则保留。
- 跳过 Lootr 装饰赞助名单的同步联网下载，避免这项没有网络超时的请求阻塞启动；不改动 Lootr 容器和玩家战利品。测试员偶发等待的日志没有线程快照，不能将所有首次等待归为同一原因。
- 未新增任务书测试地图，未加入原版地牢定位。较早测试包的范围和证据见[修订记录](REVISION2_1.4.3.md)。

关闭游戏和服务器并备份存档，移除旧版附加模组，安装`pixelmon-content-backport-1.16.5-1.4.3.jar`，服务端与所有客户端同步。JEI连接修复及巢穴捕捉动画修复继续内置，无需另装两份旧补丁。

发布提供正式JAR、功能包、9张功能地图、21张城市／展示地图、1张智皮卡地图、手册、专项指南、完整源码及SHA256文件。地图控制模组仅用于人工操作。

Java11构建、全套离线回归及实际Mixin变换检查通过；真实运行检查六星档遭遇、保存重载、旧空巢恢复和实际探测器标记。用户已确认太晶可正常对战及岩石城布局满意。长期游玩、所有整合包和设备不在本次全面实测范围，详见[验证记录](VALIDATION_1.4.3.md)。
