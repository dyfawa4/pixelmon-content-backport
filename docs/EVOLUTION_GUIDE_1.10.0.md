# 进化条件标签（1.10.0）

同行栏宝可梦的菜单增加“进化”。宝可梦详情界面底部在“概要／招式／能力”后增加同级“进化”标签：保留左侧宝可梦信息、左右切换宝可梦和原返回位置，在同一详情面板右侧查看条件。掉落物界面仅作排版参考，无需通过JEI进入。

每条路线按“宝可梦＋道具＋等级＋特殊条件→进化结果”显示。没有的条件不显示；同一结果的不同进化办法、不同分支各有独立条目。左右小按钮切换条目；长条件用鼠标滚轮滚动查看。

- 服务器读取当前生效的原生进化对象，显示使用道具、携带道具、等级、升级触发、交换、时段、天气、亲密度、招式、同行队伍、群系、步数、反作用力伤害等条件。
- 同类等级进化按原生顺序优先判定，后续分支会指出较早分支尚未触发这一前提。条件没有达成时不会把查询当成执行进化。
- 普通进化、Mega进化、道具／操作形态变化、额外进化结果分组显示。无普通后续进化时显示“（已达到最终进化型）”，仍可查看Mega及形态变化。
- 飞天螳螂列巨钳螳螂的交换／连接绳办法和劈斧螳螂的黑奇石办法；交换与连接绳路线都保留金属膜要求。
- 雨天升级等条件保留等级在前、天气在后。Mega石来自实际形态映射；烈空坐显示画龙点睛要求。厄诡椪的面具分开列出。
- 脱壳忍者额外获得方式根据原生进化结束逻辑补充；洛托姆家电形态从原生方块映射读取。其他道具形态使用已核对的操作关系，不将地区、性别或皮肤差异当作任意可转换形态。

这个按钮只查询，不执行进化、不修改宝可梦数据、不消耗道具。宝可梦蛋先提示孵化，防止提前显示其进化目标。客户端和服务端均需更新；多人游戏显示服务器当前的进化数据。

界面沿用原生同行菜单行控件、按钮纹理和字体；新增第四行及第四标签，保留原有三个操作。弹出菜单覆盖物品图标绘制，详情右面板不会残留概要页文字。

多默认形态不再逐帧随机选取；未指定具体目标形态时显示稳定代表图及目标种类。条件正文使用原生阴影文字，公式中的等号统一改右箭头，道具在来源和目标之间对齐。武道熊师区分一击流与连击流。
