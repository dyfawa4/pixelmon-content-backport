# 1.6.0 战斗规则修复

对应 [检查报告](BATTLE_LOGIC_AUDIT_1.6.0_2026-10-18.md) 的 B01—B10。当前为本地测试构建，未发布 GitHub。

## 已实施

| 编号 | 修复及边界 |
|---|---|
| B01 | 在成功添加状态后取得本次效果的真实来源，只有桃歹郎的有效毒傀儡通过招式使目标中毒时触发混乱；不再从接受者特性回调反推攻击方。受控效果上下文在 finally 中恢复，失败与道具／特性施毒不会误触发。 |
| B02 | 精神噪音改为单体、可刷新、两回合临时回复封锁；换出清除。原生回复封锁也修正为单体，保留其原有五回合长度和治疗限制。 |
| B03 | 晶光星群与太晶爆发共用分类比较，包含攻击／特攻能力等级，平手选特殊，不把道具或特性的一般能力加成误当作分类条件。 |
| B04 | 太晶爆发到达实际命中效果阶段才记录连接；收尾时消费一次该记录。保护、免疫、未命中不会凭收尾回调降低双攻，多次连接只结算一次，下一次出招清除旧记录。 |
| B05 | 密探斗篷识别明确声明的对目标追加效果；魅诱之声与精神噪音补上原生 100% Chance 元数据，精神噪音也检查其修饰结果，兼容原生追加效果控制。自身效果与主要状态效果不误挡；被斗篷跳过时恢复临时概率倍率。 |
| B06 | 太晶 60 威力下限按招式优先度而非当前行动优先度判断；保留原有多段、变动威力等排除规则。 |
| B07 | 太晶甲壳查询有效特性时传入攻击者，让原生破格等忽略特性的逻辑生效；不覆盖原属性免疫。 |
| B08 | 万能伞引起的特性刷新为古代活性传入真实场地天气，其他消费者继续使用持有者的过滤天气。 |
| B09 | 太乐巴戈斯战斗中形态变化保留已损失 HP 数量，保留满血和濒死边界。战斗结束降回普通形态仍沿用原本比例恢复策略，本次没有据战斗中规则擅改结束策略。 |
| B10 | 新建纯伤害算术服务，分步处理基础伤害、群攻、天气、要害、随机、STAB 与属性倍率。使用原生已解析的攻防、STAB 事件结果及同一次随机抽样；晴／雨倍率从威力阶段移到伤害阶段。道具回调和最终伤害事件保持各调用一次，保留团体战护盾等扩展入口。 |

另外，原生 AI 克隆与真实宝可梦共享 Pokemon、参与者和控制器，不能让克隆执行会改变真实形态、消耗太晶珠或清除全场天气的激活操作。克隆保留已生效的太晶计算快照，但不允许提交新的真实选择／激活；战斗结束清除相关快照和命中记录。此处没有重写 NPC 选招或难度策略。

## 保留规则和准确性边界

戴帽子的皮卡丘、专属 Z、爆裂场地、忍蛙强化、跨世代机制与团体战捕捉规则保持既定设计。没有修改奖励、道馆特殊奖励隔离、乘骑或已发布 1.5.0。

这些修复解决本轮报告列出的具体偏差，不构成全机制卡带一致性认证。原生特性／状态仍可能在进入伤害算术服务前处理能力和威力；原生道具／外部事件也仍执行自身算法。所有原生特性时序、其他天气招式、特性复制组合、多人同步和完整 Boss 脚本并未穷举。后续发现这类偏差，应沿用统一规则服务和针对性用例继续校正，而不是将本次结果描述为“整个战斗引擎完全官方化”。
