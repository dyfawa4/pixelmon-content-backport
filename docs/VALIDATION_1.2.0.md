## 本轮 v4 结构修复静态检查

用户对 v3 的实测证明原通路检查不足。独立复查旧模板发现 86 个模板存在悬空组件，776 处玻璃板邻接状态缺失。本轮只修改新增八城；原十城保持原状。

- 移除装饰锚点周围的无差别清空、贯穿住宅/道馆的三格宽清空，以及 NPC 到模板中心的直线拆墙。
- 门口与服务通路按实际空地连通，保护树干和承重柱；设备只放在净空地面，不能以拆除外墙和立柱腾出空间。
- 玻璃板和栅栏序列化实际四向连接，树叶保持持久；修正圆形道馆上的错误矩形门面、顶棚支撑和虫城悬空装饰。
- 432 个模板静态审核包括入口与 NPC 连通、设备可接近、原生功能/NBT 保留、接地组件和玻璃板邻接。新增故障夹具验证审核能拒绝缺失树干、全部方向为 false 的玻璃板。
- 新八城预览按住宅与公共设施选图，至少八座住宅，并拒绝超出放置边界的方案。此逻辑已经编译，实际选图结果仍由用户运行确认。
- v4 八张地图均重新生成。废弃 v3 八张移出 saves，在测试实例外备份；不在已有城市上叠加新模板。

这轮只运行编译、离线字节码、模板和封装检查；没有自行运行游戏测试。模板静态通过不代表真实地形生成、拼装外观或游戏动态验收通过。
