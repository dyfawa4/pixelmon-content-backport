# 重铸内容回迁 1.3.0

发布日期：2026-10-12。Minecraft 1.16.5 / Forge 36.2.42 / Java 11。

本版采用玩家确认的 v9 建筑，改善道馆对战、城市内饰、成就与常用指令。

- 十八类真实馆主统一高级决策、合理配招和合法满配养成，按局面评估换人、用药及 Mega、极巨、太晶、Z 招式；原十城与新八城同步，徽章只由馆主发放。
- 道馆双方每场最多成功使用三次背包道具，其中复活类最多一次。达到上限时仅提示并返回选择，不消耗物品或回合；战后归还开战前携带物。
- 新八城馆主位于主轴独立台位，设备与其他训练师避让；主入口不再并排保留旧门与新门。毒馆实验设备分区，照明按主题安排，修复封闭建筑屋顶。
- 普通玩家可使用刷新查询、传说/Mega Boss 查询、结束自身对战及十八属性道馆定位，无需作弊或管理员权限。
- 皮卡丘携带原生智皮卡 Z 自动显示初代戴帽形态，补齐正常与闪光图标。
- 修复彩虹、刺刺耳、僵尸转换及关联成就；伊布大家族要求九种不同成员全部满足。补充形态、合体和伽勒尔三鸟成就，传说续章节点完成后显示。
- 修正 960 个原生 TM/TR 名称，补齐徽章群系说明、结构与 PixelTweaks 汉化，以及建筑内嵌 NPC 姓名和对话。
- 溺水世界仅允许黑暗球，使用原生夜晚倍率；修复相关场外形态、巢穴生成器与物品交互。

升级前关闭客户端和服务器，备份存档，移除旧补丁并只保留一份 1.3.0。保留原 Pixelmon 本体，服务端与所有客户端版本一致。既有城市不原地重建；新版建筑在新区域或独立 v9 地图中生成。

提供独立补丁 JAR、功能包、九张专项地图、十八座城市与徽章展示地图、手册、完整源码及 SHA256。功能包不附带 Minecraft 或 Pixelmon 本体。编译、Mixin、资源和封装检查已通过；建筑由玩家确认，实际对战难度及整合包交互以游戏体验为准。
