# 1.6.1：战斗稳定性、刷新探测器与外观改进

发布日期：2026-10-19。适用于 Minecraft 1.16.5、Forge 36.2.42、Java 11，以及受支持的 Pixelmon 9.1.12／9.1.13 本体。正式核心使用已经确认的 1.6.1 修订 3，包含本轮全部追加修复。

## 安装与升级

- 普通玩家下载 `pixelmon-content-backport-1.16.5-1.6.1.jar`，替换 mods 中旧回迁核心，同一实例只保留一份。保留原生 Pixelmon 和其他依赖。
- 多人服的客户端与服务端必须同时更新为 1.6.1。本次队伍恢复消息使网络协议升至 13，不与旧协议混用。
- `Pixelmon-Backport-1.6.1.zip` 包含相同核心、说明和可选 FTB 任务配置；不是完整整合包，不含游戏本体、账号、玩家日志或世界。单装核心即可使用所有本次新增图标、模型和汉化，无需独立资源包。
- 可选 `config/ftbquests` 是沿用的整合包任务书章节。已有任务书请按整合包维护方案选择合并，单独使用本模组不要求覆盖。
- 保留旧存档；升级不要求更换 Java 或删除世界。源码附件和 SHA256 校验清单一并提供。

## 战斗与队伍稳定性

### 赛富豪巢穴脱战及同类空指针

修复赛富豪使用“淘金”时，AI 评估流程恢复空能力快照引起的异常脱战。检查扩展到 641 个原生战斗类，并修复四类能力变化效果中的同类快照问题；AI 模拟与实际战斗道具触发隔离。1.4.4 至 1.6.0 仍存在这条问题，1.6.1 处理此次缺陷。

修复太晶团战队友复活时对空存储的访问。现在记录真正倒下的宝可梦，分别处理玩家真实存储对象和 AI 临时对象，保留入场能力、状态、换人回调。取消生成、缺少锚点、战斗结束和模拟分支不继续提交复活，失败可重试，避免重复复活。

修复招式学习检查遇到 null 招式条目时崩溃，保留合法招式匹配和原有学习资格。

### 队伍同步与 MissingNo

修复客户端空槽收到仅含 HP 等增量数据时创建默认 0 号占位，以及收到另一只宝可梦的增量包时写到错误对象的两处已复现缺陷。增量只更新 UUID 匹配的已有有效对象；未知／错位时保留真实数据并请求服务器完整快照。完整包先验证身份，再恢复相应槽位。

恢复请求只允许连接本人自己的队伍或对应 PC 盒子，检查存储 UUID、位置范围并限流，不允许客户端上传宝可梦数据或获得编辑权限。封锁 0 号正常自然刷新与捕获，保留原生内部占位注册；不会把异常数据替换成妙蛙种子，也不批量删除存档宝可梦。

这些修复针对已证实的代码缺陷。群友固拉多对战中“倒下后无法换人、捕捉后恢复”的整段现场仍缺少完整日志，不能据此宣称还原了全部因果。详见 [修订 2 排查](FEEDBACK_1.6.1_R2.md)。

另有一份最新收到的崩溃报告实际仍使用 1.4.4，错误是单属性数组空槽的同步编码。实际旧 JAR 可复现，1.6.0 与本次 1.6.1 同输入正常；该项是提醒旧服升级，不作为 1.6.1 才首次修复的项目。

## 新道具：两种宝可梦刷新探测器

右键查询当前位置的刷新情况，沿用原生查看刷新命令的环境、时间、候选和概率。普通版与传说版各自计算 60 游戏刻冷却，正常 20 TPS 下为 3 秒；无限使用，不消耗、不损坏，不执行真实刷新。每位玩家独立，传说查询只作用于当前使用者，不带着其他在线玩家一起查询。

## 避难背包与配置生效

新增参考模组的 Eject Pack（避难背包），是宝可梦携带战斗道具。能力降低时按原生换人流程触发；修复回调广播、重复触发、AI 模拟触发和失效掉落 ID，可从大师级宝可梦奖励箱（第三档）获取。

P 配置页保存成功后更新当前配置对象及相应缓存，包括野生等级显示。实时读取设置即时采用新值；在创建战斗／生成／计时器时才读取的设置，从下一次对应创建开始生效；明确标注需重启的字段仍需重启。保留管理员权限、服务器同步、战斗中编辑限制和保存失败回滚。

## 戴帽皮卡丘：所有球禁止场外捕捉

独立物种戴帽子的皮卡丘（CapPikachu，1026），正常色和异色均禁止全部精灵球场外捕捉，沿用原生 Boss 的拒捕、提示和退球流程。场外提示改为：

> 不能在场外捕捉戴帽子的皮卡丘，任何精灵球都无效！请进入战斗后捕捉。

入场播报同步说明。**场内捕捉规则保持不变**：仍保留大师球、起源球、公园球的既有限制，其他合法球按原规则捕捉。未把帽皮改成 Boss，未加全局不可捕捉标记，普通皮卡丘不增加限制。

## 外观、显示与世界生成

- 修复骑行时探测引导线起点在玩家／坐骑之间横跳，使用实际渲染摄像机位置和方向，保留远坐标精度。
- 进化／Mega 白色光束纠正模型根偏移，中心降低至身体约 35% 高度，缩小射线长度与宽度，保留随进化展开的动画，减少遮挡。
- 补齐 Mega Z 等形态中英文显示，避免队伍侧栏出现原始翻译键。
- 宝可梦物品展示框使用展示框图标与手持变换；成功放置播放展示框声音，失败和客户端不重复播音。
- 精灵球、盖子、球盘、底座使用第二参考模组的相关材质；全部 85 张置于回迁命名空间，覆盖实际整球／球盖／GUI 加载路径并清理模型缓存。原生三维球体素材本就一致，保留原模型、球种身份和捕捉机制。
- 城市区域保护覆盖红／棕巨型蘑菇及菌盖跨边界自然生成。作用于以后自然生成／装饰的区块，不破坏性清理旧城区，不删除玩家种植或城外蘑菇。

## 成就与中文

- 蒂安希成就改名“窈窕淑女”；“万籁俱寂”改为挑战成就，保留 ID、条件、奖励和进度，不改变 FTB 任务。
- 究极发电厂补成就“啊啊啊啊啊啊啊啊啊啊”，描述“触碰究极发电厂的信号塔，并被闪电击中”。实际沿用原生在究极发电厂挖海晶灯概率触发雷击的机制：该次闪电真正击中挖掘者才授予，原概率保留；普通雷击、旁人被劈、事件取消不误发。
- 农夫乐事 1.16.5-0.6.0 全量 243 个英文语言键和 21 个成就显示均有中文，补 11 项漏译，覆盖烂番茄、字幕、死亡提示、配置名称／说明／分类。`Boo! Hiss!` 改为“喝倒彩！”，描述“向这些讨厌的袭击者扔一个烂番茄！”。31 个实际配置字段的默认值、范围、路径和重启要求不变。安装环境仅发现本体，其他附属／未来版本需另查新增内容。

## 忍蛙说明

“忍者的修养”的中文名称统一为**孤忍自修**，提示和手册同步。内部仍是 `Ninja Training`，旧存档已学招式、PP、学习资格、一般属性、特攻提升和追加行动规则均不变。

1.6.0 已发布的小智忍蛙机制继续保留：飞水手里剑每击基础威力 20、固定三击，使用前水系伤害 ×1.5，持续五回合（含当回合）；攻击前附着“蚀”，对手六项种族值各减 20、最低 1，持续五回合，HP 上限和当前 HP 按比例调整，可与其他效果共存、换下保留。重复使用刷新对应时长，不叠加同一增益。

孤忍自修特攻 +2（原生上限 +6）并追加一次行动，额外行动仅推进使用者个人计时，对手的“蚀”和其他参与者计时不因此额外推进。完整边界及学习规则见 [忍蛙专项说明](GRENINJA_1.6.0.md)。这些为沿用机制，本次没有重新调整数值。

## 发布验证

Java 11 构建、`check.ps1` 完整离线回归通过，包含实际原生 Mixin 转换、修复前后对照、球 NBT 配方、配置原生初始化、队伍恢复鉴权及场内／场外捕捉边界。490 个类均为 Java 11 字节码；正式核心与修订 3 完全相同。最终修订和发布准备未另启动游戏。

世界、网络、持久化的部分边界使用受控替身，完整回归不等于每一种多人／自然生成场景均已实测。细节见 [验证记录](VALIDATION_1.6.1.md)、[AI 空指针专项](RAID_AI_NULL_AUDIT_1.6.1.md) 与 [修订 3](FEEDBACK_1.6.1_R3.md)。
