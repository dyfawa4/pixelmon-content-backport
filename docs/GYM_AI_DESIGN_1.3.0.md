# 馆主策略核对

公开规则参考：[Pixelmon NPC Trainer](https://pixelmonmod.com/wiki/Trainer)、[Mega Evolution](https://pixelmonmod.com/wiki/Megas)、[Dynamax](https://pixelmonmod.com/wiki/Gigantamax)。原生 Advanced 模式在战术模式基础上评估有利换人；Mega/极巨需要对应装备与战斗资格。这些在线文档不是本包版本规范，实际限制以本地 9.1.13 的 AdvancedAI、TrainerParticipant、PixelmonWrapper 字节码为准。

策略参考：[Smogon 太晶实战示例](https://www.smogon.com/articles/svou-suspect-terastallization)。攻防太晶需配合本系输出、补盲、恢复、进场代价及保留收尾机会，不能见克制就随机变身。本文据此采用局面收益检查，不直接照搬其他世代/对战分级的招式合法性。

所有十八类真实馆主共享同一准备和决策入口；“实力相当”是缩放规则，馆主身份另由模板角色决定。保留原生换人资格、候补预留、进场陷阱、能力/道具、速度和已观察招式模拟。修复先倒下的零权重击杀仍压过安全换人的优先级；对原生已模拟成功的候补增加存活收益，已有强化会扣除放弃强化的代价。不会额外制造换人动作或直接读取敌方未展示的四槽。

馆主的候选选择改为合法候选中的最高优先级和最高精确权重，取消原生“相近候选”概率抽选；自己的换人预览也使用一致选择。敌方招式推断仍来自原生已观察招式/物种本系猜测。最高评分并非对隐藏行动、伤害浮动和未命中结果的全局最优，不承诺必胜。

每位馆主均补齐传说王牌，旧版本概率未获得者重赛时迁移；不足 Mega 使用者时添加同主题合法成员，满六只时替换一名普通成员，保留传说主力和特殊形态道具。配备不同的合法 Mega/Z 使用者，其他成员保留原生极巨/太晶候选。条件互斥和一次性资源继续服从原生 API；普通攻击已能先手收尾时保留机制，攻击失败不浪费机制。有限全复药/活力碎片占用正常道具行动，不免费攻击或无限恢复。

配招保留有效的四槽计划；非法、重复、不足四槽或缺少有效本系/输出的计划用实际可学习招式修复，再进行补盲。保留原等级与实力相当缩放，养成按下述合法满配规则准备。徽章仅保留在真实馆主奖励中。

第 34 项：所有真实馆主采用本体合法满配，六 V 常规配置与真正低速戏法空间的速度 IV 0 例外；觉醒力量保留原属性所需的合法 IV 奇偶组合，达到原生配置满级才按本体规则极限训练。两项 EV 252，余项 6，总额 510。性格采用原生薄荷效果，按配招与目标 Mega 形态的实际种族值分配速度、输出或耐久职责；合法的恢复/辅助四槽保留。特性选择仅使用本体当前形态可用项。养成同步战后恢复快照与保存标记，继续保留原等级及实力相当缩放；不叠加额外数值倍率。用户确认保留这套规则，让默认满级 100 级的战斗更有挑战。

离线证据为 `GYM_LEADER_AI_REVIEW_1.3.0.json`、Mixin 应用/字节码验证和独立风险边界测试。本项目标是提高挑战性，但没有运行游戏对战或胜率模拟；实际行为及难度由用户验收。

用药收尾复核：道具行动会花掉当前回合，慢速成员还需在下一次攻击后活到自己的行动，才有恢复收益。新增这两个受击窗口的检查，避免残血慢速主力连续喝药、下回合仍先被击倒；先手收尾继续优先。只使用原生观察/模拟数据，有限药物额度不变。
