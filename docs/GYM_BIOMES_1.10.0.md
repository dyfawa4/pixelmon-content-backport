# 1.10.0 r11 道馆群系修正

究极深海（pixelmon:ultra_deep_sea）在 Pixelmon 原生内部属于 MESA 分类。原版 AddToBiomes 根据 MESA 分类加入地面道馆；此前为究极沙漠岩石道馆开启究极空间的原生道馆间距，使这条残留配置也有机会生成。

本轮精确移除究极深海中的地面道馆候选，并在原生 GymStructure.Start.generatePieces 入口再次校验，防止旧群系配置仍被用于生成地面城市。普通恶地的地面道馆保持原规则；不修改群系本身分类、地形或其他结构。已生成的建筑不删除。

岩石道馆的数据原本已仅配置 pixelmon:ultra_desert，本轮保留实际生成规则，只修正磐岚徽章 JEI 地点说明为“究极沙漠（究极空间）”，并同步 extend_version13.py 的生成来源。

后台验证仅使用 .cache 隔离实例和测试地图。初始平坦测试地图关闭了 generate_features 且没有原生道馆间距，不能验证自然生成；仅在该私有副本开启结构生成并提供测试用原生道馆间距后验证。真实游戏安装与玩家存档未写入。

验证完成：PASS20。究极沙漠自然生成岩石城市，区块[-174,13]，160个部件；普通恶地地面城市仍能组装，究极深海3次强制原配置均被拒绝。真实JEI磐岚徽章信息查询通过。
