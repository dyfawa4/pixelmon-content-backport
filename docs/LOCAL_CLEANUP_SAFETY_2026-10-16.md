# 本机清理工具安全检查

2026-10-16。原 CMD 使用 LF 换行，Windows CMD 对启动行产生拆分；无删除功能的探针复现失败，改为 CRLF 后同一中文和空格路径可正常启动。此前仅检查 PowerShell 语法不足以证明双击启动链路正确。

当前 CMD 为 ASCII、CRLF，完整引用脚本路径，用 PowerShell 7 的 `-NoExit` 保持窗口；找不到运行时则显示信息并暂停。PowerShell 脚本采用 UTF-8 BOM，JSON 明确按 UTF-8 读取。Git 对 CMD 禁止换行转换，源码 ZIP 和仓库原始文件均保留 CRLF。

该工具现在严格只预览，已移除永久删除实现；传入 `-Execute` 也会立即拒绝。仅在本机审核过的项目绝对路径工作，不提供任意目录清理。检查清单根、保护目录、最新发布文件哈希、完整源码快照、路径归一化、运行中的 Java 进程，以及目标和祖先的 junction／符号链接，遇到异常即停止。

12 项安全测试全部通过，包括拒绝显式执行，以及中文／空格路径的无删除启动探针。安全测试覆盖源码、Git、存档、游戏目录、磁盘根、当前测试客户端、最新 JAR 和路径穿越的拒绝。全量预览还确实检测到旧 `.发布缓存` 内有链接并主动停止；没有降低此保护来继续处理。此前 724 项旧清单目标仍保留，未执行删除。自动审批也曾拒绝涉及递归永久删除的命令，因此此次发布只保留只读工具。

工具不属于运行时模组、不在离线测试包内，不影响正常游戏。仓库使用者不需运行它。
