# 重铸内容回迁 1.11.0

适用于 Minecraft 1.16.5 / Forge 36.2.42 / Java 11 / Pixelmon 9.1.12～9.1.13。正式发布采用已交付的 r12 核心，汇总 1.10.0 之后的更新。

## 下载与安装

一般玩家下载 **Pixelmon-Backport-1.11.0.zip**，另提供独立核心、源码和 SHA256 校验文件。

关闭游戏与服务端，双方替换旧回迁核心，mods 内只保留一份 1.11.0；保留 Pixelmon 本体、依赖及存档，无需独立资源包。完整包不是游戏客户端，不含游戏本体、存档或测试助手。config 中的 ironfurnaces-client.toml 可按需覆盖以关闭更新提醒。

可选忍蛙增强 **1.0.4** 默认不启用；原来使用该增强的玩家需双方同步替换旧版，基础／增强模式保持一致。

## 无尽携带物

新增23种独立注册的无尽携带物，不包含树果和属性宝石。九个同类普通道具合成一个，只通过该配方获取，不加入掉落、商店或奖励池。

每件无尽携带物**每场战斗只能触发一次**，触发后保留实物；换场不会刷新次数，新一场战斗恢复。触发条件沿用普通道具规则，拍落、戏法等移除／交换效果仍有效。旧候选版的适用无尽标记物品会迁移为独立道具。JEI 区分普通与无尽版本。

可参加训练家对战，重复携带物条款继续生效；作者道馆前三回合的携带物禁用规则保持。

## 捕捉、采集与奖励

- 新增光谱球：普通精灵球捕捉倍率，捕获成功后有50%概率变为异色，已有异色不会变回普通。普通红白球外观仅上盖改为金色，背包、同行栏及投掷模型统一；不属于智皮卡喜欢的球。
- 光谱球配方：普通精灵球上方放光鳞粉，产出一个。光鳞粉只由真正的野生异色宝可梦必定掉落一个，不包括Boss；加入一级精灵球奖励箱。
- 作者道馆球类奖励为光谱球15%、耀光球5%、大师球30%、GS球50%，四选一；保留七份不重复随机战利品及其他既有特殊奖励。JEI 与实际奖池同步。
- 山地三色玉石自然生成概率提升至配置的十倍，上限100%，只影响新生成区块；玉石上方禁止放置或自然生成雪。
- 每次实际击倒敌方宝可梦可同时给三种三圣鸟召唤珠充能，涵盖训练家、钓鱼、极巨及太晶巢穴战斗；捕获、逃跑不额外按击倒充能。
- 果实收集器补充耐久与时运附魔说明；采摘、铁砧附魔及钻石修理规则继承1.10.0。
- 删除流星／极巨腕带的旧粉色村民任务，保留其他腕带途径。

## 战斗与稳定性修复

- 修复馆主AI预测龙箭时修改不可变目标列表，导致首发出招或换入多龙巴鲁托就结束战斗的问题，保留原生单双打与两段伤害。
- 小智版、常驻小智版忍蛙持对应进化石可在战斗中Mega；修正当场获得常驻后再Mega的战后还原，补齐孤忍自修回忆。
- 修复场外求雨／大晴天的天气计时，默认支持多人使用；保留原生露天条件、成功扣1PP、失败不扣和5分钟冷却。
- 修复极巨巢穴部分招式预览分类继承缺失引起的空指针。
- 空展示器使用待设置占位，交换前检查请求与数据有效性；异常请求保留数据，已有损坏数据不会自动恢复。
- 精妙背包增加铁砧改名输出及预览隔离保护，不重置原存储引用或内容。
- 修正 Architectury 事件并行注册越界；同步探险家指南针专用服务端模型配置初始化修复。

## 显示与交互

补齐四种颜色时钟缺失的生存掉落表；创造模式仍按原版不掉落。经验奖励提示改为附魔之瓶图标，删除重复宝可梦掉落JEI页面，统一部分道具及六种洗翠球说明，修正宝珠素材、放置音效、物品拖拽入口和一次性太晶爆发技能盘手持模型。隐藏内容不在JEI与创造分类／搜索中列出，正常注册和既有机制保留。

## 验证与待观察
