# 重铸内容回迁 1.8.0

面向 Minecraft 1.16.5 / Forge 36.2.42 / Java 11 / Pixelmon 9.1.12～9.1.13。本次汇总 1.7.0 之后的全部更新，正式版沿用已完成分项检查的 r15 核心。

## 安装与下载

- 一般玩家下载 **Pixelmon-Backport-1.8.0.zip**。关闭游戏及服务端，双方替换旧回迁核心，`mods` 中只保留一份 1.8.0；保留 Pixelmon 本体、依赖和存档。网络协议为 19，双方须使用同一版。
- 将包内 `config/ironfurnaces-client.toml` 一并覆盖到实际客户端实例并重启，才能关闭万能熔炉的更新检查及聊天提醒。仅替换 JAR 不会应用此配置。
- 不需要额外资源包。本包不是完整整合包，不含 Minecraft、Pixelmon 本体、个人存档或自动测试助手。
- “我的天哪忍蛙大人”默认不启用。需要增强时，双方另行安装可选目录内的 **1.0.1**，替换旧 1.0.0；此小版本仅扩展兼容范围。基础版不提供飞水手里剑的额外水系强化、孤忍自修的额外行动；可选模组恢复五回合水系威力×1.5和额外行动。下回合优先度提升沿用既有规则。
- 独立核心、完整源码、玩法手册、更新说明及 `SHA256SUMS-1.8.0.txt` 同时提供。既有测试地图仍保留在旧版 Release，本次功能包不附地图。

## 作者道馆、奖励与战斗

- 优化AI战斗逻辑。
- 普通馆主保留六只队伍及两个本属性神兽位；普通馆主与作者成员均使用六项个体值31、六项努力值252，并匹配性格与配装。
- 作者六只队伍改为两个原有核心、两个额外强力位、两个联防配合位，取消属性限制。强力池包括智皮卡、传说石板阿尔宙斯、Mega小智甲贺忍蛙、无极巨化无极汰那、黑马王和白马王，允许重复抽取；固定成员不占额外强力位。
- 平原固定传说石板阿尔宙斯，海洋保留原始盖欧卡，沙漠固定原始固拉多，沼泽固定无极巨化无极汰那，恶地保留智皮卡。已有作者更新阵容时保留逐人挑战与领奖记录。
- 取消作者战中攻击命中、守住、自身增益及回复的额外30%惩罚，恢复原生结算与命中显示。
- 玩家效果型携带物在整场战斗前3回合禁用，第4回合恢复，换人不重置。Mega石、Z纯晶、面具、石板、红蓝宝珠、腐朽的剑盾等形态机制道具仍正常生效；被限制的道具不会因此消耗。作者挑战新增禁止玩家使用无极巨化无极汰那。
- 作者及溺水Boss的常驻削弱独立命名为紫色 **“祸”**，忍蛙的五回合 **“蚀”** 保持蓝色。默认各降低六项种族值20点，可叠加至各40点、最低1；与雷之誓约分别显示。治疗仪、治疗指令、幸运方块宝可梦手机可清除，普通回血招式及药物不能解除。
- 修复削弱状态治疗后上限、当前血量及倒下状态缓存不同步，避免血量显示异常和换入已倒下的宝可梦。
- 作者奖励改为 **七份不重复随机物品**，合并传说、究极Boss物品池并按物品和NBT去重，补入红色锁链、下界合金背包、心之水滴。大师球独立 **50%** 获得1个；首次智蛙石必得，此后1%。金币沿用50万～100万规则。
- 修复作者胜利偶发不发奖、断线丢失待领奖励和重复发奖问题。每名玩家击败同一作者后锁定，失败可重试，其他玩家仍可挑战；作者免疫直接实体攻击。
- 修复NPC编辑器打开作者时皮肤索引越界，以及相关战斗属性通知崩溃。普通Mega甲贺忍蛙不再误抽作者专属智蛙石，Mega Boss首次必得、之后按等级2.5%／5%／10%的原生奖励规则保留。
- 野外可见大师球奖励箱的大师球独立概率固定为 **1%**；隐藏箱保留15%高级池分流，总概率为 **0.15%**。补齐道具商店奖池等获取来源的中文名称。
- 新隐藏挑战 **“你去spa！！！”**，描述“做了不该做的事情”：对作者使用命名牌会阻止改名、消耗使用者携带的所有命名牌并立即死亡，创造模式也生效；死亡描述为“玩家名做了不该做的事情!”。
- 每次击败任意等级Boss、普通馆主或作者时播放原版挑战成就完成音效，同场重复通知只播放一次。

## 新道具与获取

- **神秘药剂**：右键自己的宝可梦，沿真实进化链退回上一阶段，成功消耗1瓶；没有上一阶段时无效且不消耗。保留个体身份和培养数据，再次喂糖可沿记录恢复，支持连续退化后逐步恢复。蛋、临时变身及战斗中不可用。
- 神秘药剂配方为：睡莲／垂泪藤／金合欢树苗；究极丛林树苗／金苹果／仙人掌；**草**／**水瓶**／诡异菌。草不是海草，水瓶须为原版水药水。可从各等级Boss（包括溺水）及精灵球、高级球、大师球、究极球奖励箱获得，**作者道馆不掉落**。
- **搬家协议**：界面选择队伍宝可梦和拥有的原生球种，成功消耗1份协议及1个目标球，原球不返还。支持物品栏与原生宝可梦背包的打开／关闭状态；排除公园球、奇异球、起源球，同球种、蛋、他人宝可梦及战斗中不消耗。
- 搬家协议配方为：荧石／任意精灵球盖／工作台；任意颜色的床／石头按钮／熔炉；箱子／铁、铝或铂制球座／**唱片机**。图标为打开的精灵球、迷你橡树及小河。
- **变性魔药**：切换自己宝可梦的雌雄，成功消耗1瓶并保留其他数据；无性别、固定单性别、智皮卡、蛋及战斗中不可用。没有酿造配方。
- 搬家协议与变性魔药各以独立5%概率加入新生成的村庄道具商店箱子，并加入精灵球／高级球奖励箱、普通补给站及普通／优秀／罕见／史诗Boss常规奖池；旧箱子不追补。
- **缩小灯／放大灯**：右键自己的宝可梦调整一个原生体型等级，成功消耗1个，极限或失败不消耗，战斗中不可用。红／绿直筒手电筒采用像素图标与立体手持模型。
- 缩小灯：左右六铝锭，上中海晶灯、中央绯红菌、下中红石中继器。放大灯：左右六铁锭，上中红石灯、中央极巨菇菇、下中红石比较器。两灯加入高级球／大师球箱、史诗／传说／终极Boss及作者合并奖池。
- 补入 **特性护具** 的战斗机制、获取方式及中英文说明。
- Pixelmon四种钓竿支持原版附魔台、铁砧、砂轮。饵钓Ⅰ～Ⅲ使等待时间变为1/2、1/3、1/4，最低1秒；海之眷顾每级增加实际“！！！”稀有候选权重50%。耐久、经验修补及诅咒沿用原版适用规则。

- 移除TCG卡牌的展示、搜索、配方、战利品及专属建筑自然生成入口，已有建筑保留。
