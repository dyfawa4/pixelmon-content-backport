# 1.4.1 修复与追加需求

记录日期：2026-10-13。1.4.0已发布，当前本地修复版依次处理以下项目。不覆盖运行中模组与已有测试存档；完成新追加后需重启客户端才能验收新内容。最新交付要求（2026-10-14）：完成1.4.1回归检查后发布至GitHub，详细说明忍蛙技能更新。此前仅离线交付的限制已被此要求替代。

1. 修复点击多人游戏引起的StackOverflowError：阻断推广下载时不再同步或延迟执行新建多人界面的完成回调，保留自存服务器、直接连接与局域网发现。
2. 修复平原村庄神兽查询与实际生成缺少智皮卡：更正旧结构名称，智皮卡专属判定使用完整村庄结构引用，查询与生成一致；保持真实平原村庄、70级、捕获率3及原生生成率减40个百分点。
3. 智皮卡固定公性：独立CapPikachu只能为公，新生成、正常/闪光、队伍与PC读档以及已有雌性个体均校正；保留UUID、养成、招式、携带物和闪光。普通皮卡丘与其他物种不改。
4. 探险家指南针和自然罗盘完整汉化：覆盖两模组当前版本所有界面键，以及本整合包注册结构、生物群系、维度与来源显示；检查实际名称显示路径，不能只补没有被界面使用的语言键。保留搜索/传送/缓存/属性筛选及英文模式，可选模组缺失不影响启动。
5. 击败智皮卡必定掉落大师球与智皮卡Z：每次实际击败可产生战利品的野生独立智皮卡，原生战利品流程固定大师球1个、智皮卡Z1个；不重复发奖，不把捕捉、逃跑或普通皮卡丘误算，也不通过挑战自己的宝可梦或NPC队伍刷取。保留原生战利品领取方式。

6. 神兽查询显式区分全局生成率与候选权重，存在智皮卡候选时补充其专属生成率（配置70%减40个百分点为30%），不改变原生候选选择、计时、其他神兽概率或重复扣减。

7. ZA新增Mega Boss头像统一为原生像素风格：检查每个Boss的实际形态、普通/闪光及头像资源，不只修大竺葵。保留已有合格像素资源，替换模型头像并核对显示路径。
8. 增加Mega烈空坐成就“凌云九霄”：自己的烈空坐成功完成场外或对战内Mega进化后达成；使用Mega形态图标，转换失败、取消、模拟、NPC及直接获得Mega不计入；不修改任务书。
9. 巢穴单独排除智皮卡：原生极巨化与新增太晶巢穴的自然选怪/生成池均不能选出独立CapPikachu（智皮卡）；其唯一自然刷新来源仍为实际平原生物群系的真实村庄。检查实际选怪与生成入口，避免仅修改一份静态列表。按前述项目顺序完成；保留人工测试台与管理员测试能力。
10. 智皮卡Z删除原生旧描述（戴帽皮卡丘的十万伏特升级为Z招式），保留独立智皮卡、千万伏特转换为雷之起源、爆裂场地及获取方式的新说明。只针对智皮卡Z，不修改其他Z纯晶或任务书。

最终交付要求：编译、回归检查、封装后发布1.4.1，忍蛙专项规则随发布文件和手册提供。
