# 重铸内容回迁 1.8.0 修订历史

正式版统一规则及安装方式见[1.8.0发布说明](RELEASE_1.8.0.md)。以下为本地测试各轮记录，早期外观和临时规则以正式说明为准。

2026-10-25 修正版 r12：溺水Boss及作者道馆的常驻效果独立命名为祸，使用紫色祸字圆形标识；忍蛙的蚀保持蓝色。效果与数值不变，三种效果可同时存在，图标分别排列。搬家协议支持所有颜色的床，右下材料更正为唱片机。捕获进入PC后暂时不可见的同步链路也已补齐：缺失/首次初始化、限流补发排队，以及捕获实际入库后的单槽补发。包含r11全部功能及修复。客户端与服务端需同时更新同一核心（通道19）。

适用于 Minecraft 1.16.5、Forge 36.2.42、Java 11、Pixelmon 9.1.12～9.1.13。下文保留正式发布前的测试记录。

## 战斗与作者挑战

- 优化AI战斗逻辑。
- 普通馆主保留两个本属性神兽位，不加入作者专属额外强力位。普通馆主和作者成员六项个体值31、六项努力值252，修正性格按招式与职责选择。
- 全部作者队伍取消原有属性限制，补充联防与配合。队伍保持六只：原有两个核心位、两个新增强力位、两个联防配合位；强力位允许重复抽取，固定成员不占新增强力位。
- 强力池包括智皮卡、传说石板阿尔宙斯、Mega小智甲贺忍蛙、无极巨化无极汰那、黑马王、白马王。作者成员个体值和六项努力值全部拉满，性格与配装匹配。
- 平原固定传说石板阿尔宙斯，海洋保留原始盖欧卡，沙漠固定原始回归固拉多，沼泽固定无极巨化无极汰那；原有恶地固定智皮卡保留。已有作者会安全更新阵容，保留各玩家挑战及领奖记录。
- 取消作者战攻击命中、守住、自身增益及回复的额外30%惩罚，均按原生规则结算；连续守住等原生限制保留。
- 战斗招式面板恢复原生命中显示。
- 玩家效果型携带物在整场战斗的前3回合禁用，换人不会重新计时；从第4回合起恢复正常触发，不再附加失败概率。包括气势披带、黑色污泥、吃剩的东西、树果、宝珠及普通增益道具。
- 面具、Z纯晶、Mega石、石板及必要的形态机制道具正常生效，包括红色/蓝色宝珠、腐朽的剑/盾等；普通数值增益道具不因此获得豁免。不移除或消耗因限制而未触发的道具，战后仍按原规则归还携带物。
- 保留原有作者挑战队伍限制，新增禁止玩家使用无极巨化无极汰那。
- 智蛙施加的五回合蚀可以与常驻祸叠加，显示独立图标；默认各降低六项种族值20点，合计各40点，最低按1计算。蚀到期后仅移除蚀，祸保持，雷之誓约也可同时生效。原有数值和取整规则保持。
- 修复作者战斗中相关属性通知与模拟副本导致的空指针崩溃。
- 作者NPC免疫直接实体攻击。每名玩家击败同一作者后锁定，失败可重试；作者保留，其他玩家仍可挑战。胜利、领奖防重及十胜成就记录分别保存。
- 作者奖池新增红色锁链、下界合金背包、心之水滴，每份各1个；并入传说和究极Boss等级奖池物品，按物品及NBT去重。每次抽取七份不重复随机奖励，大师球独立50%获得1个，不进入七份随机池；首次智蛙石奖励保持。
- 野外可见大师球奖励箱的大师球概率固定为1%，不随奖池数量改变；隐藏奖励箱保留原生15%的高级池分流，获得大师球的总概率为0.15%。普通精灵球、高级球外观的可见奖励箱保持原规则。
- 修复作者战偶发胜利不发奖：依据原生胜负结果记录胜利，在战斗结束后发放；保留逐人胜利锁定。奖励记录保留到领取完成，断线后恢复未领取部分，不重新抽奖或重复发钱。
- 修复NPC编辑器右键作者时自定义皮肤索引越界崩溃，保留作者外观及编辑保存。
- 修复普通Mega甲贺忍蛙误抽作者专属智蛙石而导致首次奖励落空。Mega Boss仍沿用首次必得、之后按等级2.5%／5%／10%的原生规则及玩家记录。

- 描述：可以切换已有宝可梦居住的精灵球，使用后该道具和精灵球会消耗。

- 缩小灯改为红色直筒手电筒，放大灯改为绿色直筒手电筒，大小统一。背包采用像素图标，第一/第三人称手持、掉落与展示框使用配套立体手电筒，带银色灯头、灯镜、筒身和尾盖。搬家协议打开的精灵球内改为迷你橡树和蓝色小河。所有已确认配方、掉落及功能保持。
