# 咖喱食材配方（1.10.0 r4）

以下配方每次均产出1份。对物品按R可在JEI查看配方，信息页同步说明获取方式。

## 无序合成

| 食材 | 材料 |
|---|---|
| 通心粉 | 小麦×3＋鸡蛋×1 |
| 即食面 | 通心粉×1＋干海带×1＋碗×1 |
| 香肠 | 生猪排×2＋干海带×1 |
| 肉汁 | 牛排×1＋熟猪排×1＋碗×1 |
| 鲜奶油 | 牛奶桶×1＋糖×1，返还空桶 |
| 特选苹果 | 苹果×9，放满3×3合成格 |
| 即食咖喱 | 即食肉排×1＋即食面×1 |

## 有序合成

表内每个“／”分隔一行，“空”为空格。杯子均为 `pixelmon:mug_base`。

| 食材 | 三行摆放 |
|---|---|
| 炸物拼盘 | 空、空、空／熟鸡肉、熟羊肉、牛排／空、杯子、空 |
| 即食肉排 | 空、空、空／空、通心粉、空／熟鸡肉、熟兔肉、熟羊肉 |
| 豆子罐头 | 空、可可豆、空／可可豆、空、可可豆／空、杯子、空 |
| 巴哈罐头 | 空、糖、空／粗骨头、骨头、贵重骨头／空、杯子、空 |
| 香料组合 | 空、橙色郁金香、空／红色郁金香、粉红色郁金香、白色郁金香／空、玻璃瓶、空 |
| 超极粉 | 极巨菇菇、极巨菇菇、极巨菇菇／极巨菇菇、极巨糖果、极巨菇菇／空、极巨汤、空 |

粗骨头为 `pixelmon:thick_club`，普通骨头为 `minecraft:bone`，贵重骨头为 `pixelmon:rare_bone`。超极粉共需五个极巨菇菇、一个极巨糖果、一个极巨汤。原生有序合成支持水平镜像；未占满三行的配方可在合成格中上下平移。

即食面需要的通心粉、即食咖喱需要的即食肉排均可用本表配方制作。新增配方不修改已有任务奖励和店员库存。
