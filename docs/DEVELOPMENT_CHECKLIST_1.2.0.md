# 1.2.0 开发验收清单

本文件面向开发和验收；玩家 README、手册和发布说明不引用隐藏配置细节。

## 隐藏配置

- 毒系道馆实力相当 NPC 在需要生成新王牌时，约 70% 选择无极巨化的无极汰那；其余保留随机选择，不能每座毒系道馆完全一致。
- 必须携带回迁模组的 `eternatus_meteorite`（无极陨星），由正常携带道具机制产生无极巨化形态。
- 配招固定为极巨炮、污泥炸弹、喷射火焰、自我再生，验证为该物种合法招式；原有等级不提高，IV/EV 不额外强化。
- NBT 保存并重新载入后保留同一只宝可梦、携带物、形态和配招；修补旧版已生成的该王牌时也保留身份和等级。
- 其他属性王牌从可战斗的候选物种中变化，不使用每种属性固定一只的表格。
- 普通实力相当 NPC、非实力相当道馆 NPC、禁用增强的 NPC 不受此配置影响。

## 城市与战斗

- 全部十八种属性主题（原有十种 + 新增八种）各有完整街区、公共设施、主道馆、主题特色和可获得的专属徽章；逐一验收原有十种的模板和奖励。
- 模板池连接与实体奖励由原生游戏读取，实际拼装城市时不得存在缺失模板。
- 新城市保持所用原城市完整模板数量、街区布局和物资设施，自然生成使用原生城市生成尺寸；十八种属性各有独立城市测试地图。
- 新道馆队伍初始化一次，并保持训练值和等级；重复载入不得重抽。
- 对战决策使用已公开或观察到的对手信息；治疗占用正常回合，变身遵守原生限制。
- 具体测试结果填入版本验证记录；未通过项不得标注为已完成。
