# 太晶化外观回迁计划

记录时间：2026-10-17。状态：用户已同意方案；第一版样板实现和离线回归完成，等待手动局内外观验收。

## 已确认的范围

用户同意直接回迁高版本 Pixelmon 的太晶冠冕，沿用本项目既有高版本内容回迁方式。优先使用官方 9.4.1 的模型与贴图，保留上游归属，不引入其他模组代码或把上游素材标为 MIT 原创。

目标是在现有太晶化机制上补齐局内外观：原宝可梦模型的结晶效果、18 属性与星晶的 19 种冠冕、不同体型的佩戴适配，以及多人可见性和结束清理。保留原模型、动画、异色和既有战斗规则；厄诡椪、太乐巴戈斯继续使用各自特殊形态。

用户补充确认：身体效果可以采用类似极巨化表面覆盖的方式，叠加对应太晶属性颜色的结晶光泽和粒子；**不能变大**。不得修改实体尺寸、碰撞箱、原模型缩放或调用极巨化变大逻辑；冠冕作为独立附件显示。

用户特别要求包括自制戴帽皮卡丘（`CapPikachu`，全国编号 1026）。将其正常/异色模型加入专项定位和地图，保留原帽子、体型、动画、招式与专属战斗机制；额外冠冕放在帽顶上方，避免与帽子重叠。它与普通皮卡丘、小智帽形态分别核对。

## 实现顺序

1. 提取并记录官方高版本冠冕、贴图及定位数据，验证完整性、格式、依赖和哈希；转换为 1.16.5 能读取的资源。转换工具可重复执行，不依赖分发完整上游 JAR。
2. 确认旧版模型及渲染接口，增加共用身体结晶渲染层与冠冕附件。优先绑定头部骨骼；无适合骨骼时使用明确的定位规则与可配置修正。
3. 服务端同步实际太晶状态，支持自己、对手、旁观者及附近玩家；换下、倒下、战斗结束、实体卸载、切换世界或断线后清理显示。
4. 先形成可试玩样板，覆盖双足、四足、蛇形、飞行、大型和特殊形态。验证后完成全部 19 属性及模型覆盖审计。
5. 完成 Java 11 构建、Mixin 与协议回归、资源覆盖校验、手动验收地图和说明。通过验收后再制作新的离线包；保留已交付的 NPC 任务版本及原任务文案。

## 验收标准

- 19 种冠冕均有实际可加载的模型和贴图，来源可追溯。
- 共用渲染覆盖旧版本体和本项目新增种类/形态，不以复制每只宝可梦身体模型实现。
- 保留原有动画、异色和特殊形态；无明显冠冕穿模或异常比例，异常体型可独立修正。
- 太晶时身体有可辨认的结晶变化，效果以旧版渲染验证为准，不预先宣称与朱紫完全一致。
- 多人状态正确，无战斗结束后残留、其他战斗串状态或客户端自行决定战斗状态。
- 远处及多实体场景控制渲染开销；独立服务器能够加载，不错误加载客户端类。
- 原太晶战斗机制、NPC 任务及已验收地图回归通过。覆盖审计与实际目测分开记录，不把静态检查等同全部物种人工验收。
