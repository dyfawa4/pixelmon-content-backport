# 1.4.3 本地修复与城市优化

日期：2026-10-15。本轮生成本地测试补丁与配套地图，不覆盖已发布的1.4.2制品。

## 忍蛙显示与播报

招式页根据当前宝可梦的种类、形态和牵绊特性显示飞水手里剑。小智形态显示基础威力20、固定3击，并说明使出前强化自身、三回合水系威力提升50%的效果；普通忍蛙和其他物种不改动。描述按字体宽度换行，避免连续中文超框。此页面展示基础威力，不将战斗中的临时50%加成写成永久数值。

已核对最新截图和测试存档：蓝色头冠的个体仍为 `battle_bond` 普通外观，显示15威力、2～5击正确。原生小智头像为红色头冠、背后蓝色手里剑。普通形态的描述不提前替换为进化后的效果。

强化时明确播报「某某强化了自身！水系攻击威力提升50%，持续三回合！」，到期播报「某某的水系伤害加成结束了！」。两条消息在原生战斗消息读取入口解析中文／英文目录，避免资源覆盖造成遗漏。名字采用单一占位符替换，百分号和带百分号的昵称不会被误当成格式符。

保留当前攻击立即受益、包含使用当回合的三回合计时、重复使用只刷新、仅自身受益、换下／倒下／战斗结束清理的规则。不改动亲自触发牵绊进化取得常驻形态的原生击倒条件。

实测追加修正：对战选招侧栏也根据小智形态显示飞水手里剑每击基础威力20，普通形态仍为15；Z招式、极巨招式保留原显示。修正此前仅详情页更新、对战侧栏遗漏的问题。

加成到期重复三次的原因为AI模拟副本保留相同对战控制器，模拟结束后也参与了到期播报。现在永久区分该次对战中的模拟副本与真实参战包装对象，副本可计算加成，但不播报；模拟回合也不能消耗真实个体的加成状态。到期、换下和倒下仍按原规则清理。

## 手动测试点

复用「02 换形与技能回忆测试」初始地图，新增明确标记的测试入口：

- **牵绊进化测试（普通外观→小智）**：提供未变身的牵绊忍蛙，招式为飞水手里剑、守住、冲浪和撞击。对手改为原生训练家队伍，每次只上场一只，首发卡比兽、后备幸福蛋；修正旧场景将两只野生对手同时上场的问题。在原生训练家初始化回血后，将首发设为1HP，再向客户端刷新对手快照，避免只改服务端血量。
- **忍蛙强化与结束播报（保留现有个体）**：使用现有小智忍蛙，对手为仅会跃起的100级幸福蛋。先用飞水手里剑，再守住两回合；重复使用飞水手里剑会刷新计时。
- **检查忍蛙形态与个体身份**：显示当前进化状态、外观区别、招式基础数值、特性和UUID，以及当前对手血量和后备状态。方便比较战斗前后、PC存取和重进后的同一个体。对战状态变化时也会提示未变身／已变身。

02地图初始化一次后保留队伍和背包；旧地图已经取得常驻小智忍蛙时也避免自动重置。只有主动使用重置或新建队伍测试点才更改测试队伍。初始选择界面仅在测试地图服务端已准备好队伍后关闭，不改变普通生存存档的初始选择流程。

可用 `/backportqa map ash`、`/backportqa map ashboost`、`/backportqa map ashstatus`；战斗中可用 `/backportqa map end` 结束测试。

## 太晶巢穴遭遇与探测器

修复图鉴编号字符串被当作宝可梦名字，导致新太晶巢穴合法遭遇被误判不符合群系并清空的问题。数字编号与名字分别使用正确原生入口，原有群系／维度及智皮卡排除规则保留。空太晶巢穴与空极巨巢穴一样隐藏引导线，刷新出宝可梦后恢复；空巢提示不再误写为已经挑战完成。旧版异常空太晶巢穴首次升级加载可重抽一次，此后状态保存，不会每次重进重置。

主世界独立160万次生产分流抽样，太晶50.038%、极巨49.962%；没有修改两类自然巢穴各50%的分流规则。新世界已保存主世界区块中实际统计太晶12、极巨10，属于小样本。检查方法、证据与用户对战确认见 `DEN_AUDIT_2026-10-15.md`。

## 追加：已领取补给站引导线

用户要求暂缓GitHub发布，先处理已开过的补给站。探测器原先已经根据原生`PokeStopTileEntity.canClaim(PlayerEntity)`显示能否领取，但始终绘制引导线。现在仅在绘制引导线前检查当前玩家的原生领取状态：尚不可领取时隐藏，恢复可领取后显示；一次性补给站继续按原规则保持已领状态。保留标记、信息、奖励内容和服务端同步机制，不以点击或其他玩家的领取判断已领取。

不保存本地已领坐标缓存，旧世界／失效／替换／未加载的补给站不画线，也不为了检查而加载区块。生产构建、真实探测器Mixin变换和离线客户端边界回归通过；本追加项尚未进行游戏画面实测。
