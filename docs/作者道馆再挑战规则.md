# 作者道馆再挑战规则

首次取得有效胜利后，后续挑战启用以下规则。旧存档已完成的首次胜利进度也计入。

| 规则 | 第二次及以后 |
| --- | --- |
| 队伍重复 | 同一图鉴编号只允许一只。 |
| 智蛙和智皮卡 | 只能选其中一种参战。 |
| 阿尔宙斯 | 禁止携带传说石板参战。 |
| 无极汰那 | 禁用携带无极陨星的无极汰那和无极巨化形态。 |
| 百变怪、梦幻和图图犬 | 禁止参战。 |
| 作者剩余 1–3 只可战斗宝可梦 | 作者攻击招式打玩家时，有限的属性克制倍率按 3 倍计算，原倍率达到 4 倍时按 4 倍计算。作者复活队友后会按剩余数量重新判断。 |

以下规则从首次挑战起就适用。

| 规则 | 效果 |
| --- | --- |
| 用药 | 玩家不能用药，作者可以。 |
| 携带物 | 玩家效果型携带物前 3 回合休眠，第 4 回合恢复。面具、Z 纯晶、Mega 石、石板和形态机制道具不受限制。 |
