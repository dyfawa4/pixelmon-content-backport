# Mega 外观差异核查（2026-10-19）

本次仅诊断，不改动正在运行的客户端或视觉资源。

| 问题 | 当前确认 | 判定 |
| --- | --- | --- |
| 三种米立龙 Mega 完全相同 | 当前三条来源路线引用同一份旧平滑 PQC、普通／闪光贴图与动画；官方图鉴分别列出三种 Mega，图片资源不同 | 现有平滑素材的变体外观尚未补齐；不能当成官方三个完全相同 |
| 两种玛机雅娜 Mega 完全相同 | 当前两个来源引用同一套旧平滑模型及普通／闪光贴图。官方普通 Mega 和500年前颜色 Mega分别有图鉴条目和图片 | 原始颜色 Mega 的专用配色尚缺，不应拿闪光代替 |
| 皮可西 Mega 翅膀异常观感 | 与用户原始定制 JAR逐项比较：解码及旧版骨架辅助名适配后，身体、待机、行走 BMD 字节一致；原骨架、动画帧、蒙皮几何、普通贴图、自发光 PNG 全一致。左右翅膀各有1677个加权顶点 | 排除此次米立龙／玛机雅娜资源替换及几何转换改坏的情况。不能仅凭静态截图判定原设计正常；仍需核对原作姿态及当前渲染／动画表现，列为待查 |

## 皮可西薄翼专项复核

再次检查左右翅膀，每侧完整归属该翼骨骼的三角面为411个；法线同时朝向正、反两侧（投影约 -1 到 +1），不是只有一侧表面。坐标在最佳拟合平面法向仍有约0.108的跨度，对比主跨度2.503，表明源实现为非常薄的翼面结构，不能称作完全零厚度的单面片。模型、骨架、动画和原贴图此前已逐项与提供的源 JAR 核对一致，当前外观补丁仅处理801／978，没有改皮可西。因此未发现回迁丢面、压扁或蒙皮转换导致的故障，薄片观感首先属于原模型表现。

[官方图鉴](https://zukan.pokemon.co.jp/detail/0036-1)的原始公开数据描述其借月光力量操纵周围重力飞行；没有提供翅膀具体厚度规范。不能由这段设定推导“官方规定绝对零厚度”，也未取得官方游戏原生网格来作逐顶点比对。当前保留薄翼，不按已经证实的 bug 擅自加厚。
