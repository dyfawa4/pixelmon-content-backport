本次更新根据测试反馈修复地图安装与道具问题，补齐物品说明和 JEI 信息。

- 修复测试地图配套模组缺少资源包元数据导致的 ResourcePackInfo 加载错误。
- 整理地图压缩包结构：顶层直接提供 `mods/`、`saves/` 和说明，解压一次即可安装七张独立地图。
- 新增道具按住 Shift 可查看用途、使用条件和获取方式。
- 太晶巢穴的探测器等级显示改为 R1—R6，与极巨巢穴一致。
- 新增独立的“一次性太晶爆发技能盘”，太晶巢穴胜利固定获得一张；成功学习后消耗，取消或无法学习不消耗。原有可重复使用的太晶爆发学习器保持原规则。
- 完善 JEI 联动：70 个新增物品和 8 张相关学习器均可查询用途、来源及招式说明；游戏内信息只包含玩法内容。
- 优化实力相当 NPC 的对战逻辑。

请关闭游戏并备份存档后升级，功能模组与地图配套模组各只保留一份新版 JAR。多人游戏需客户端与服务端一起更新至 1.1.0。

已完成 Java 11 构建、Mixin 注入检查、隔离 Forge 服务端回归，以及带 JEI 和地图配套模组的客户端检查。详细记录见 [测试记录](https://github.com/dyfawa4/pixelmon-content-backport/blob/v1.1.0/docs/VALIDATION_1.1.0.md)。
