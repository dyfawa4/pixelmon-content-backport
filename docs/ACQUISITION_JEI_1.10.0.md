# 第二章食物与药品的 JEI 获取来源

在 JEI 中指向物品按 R，查看对应分类：

- 店员与售货机购买：区分宝可梦商店主店员、副店员和野外店员。店员页列候选商品，实际是否上架及售价以交互界面为准。售货机页显示基础购买价。
- 宝可梦掉落：显示物种、个体条件、数量范围与基础掉落概率。
- 料理锅制作：咖喱成品对应主食材和树果要求，风味、评级仍由实际烹饪决定。
- 建筑与奖励箱：补充原生精灵球、超级球、大师球及究极空间奖励箱候选物品。
- 信息：显示咖喱食材的合成材料与制作说明。普通合成、树果炼制器等既有 JEI 配方继续使用原分类。

店员、掉落和奖励箱目录来自服务器已加载的数据；查询不会随机生成库存、抽取掉落或领取奖励。咖喱按原生食材枚举映射。服务器定制店员的实际库存可能不同，以实际交互为准。

此前没有常规来源的六种食材已在 r3 补上无序合成：通心粉、即食面、香肠、肉汁、鲜奶油、苹果食材。在 JEI 的合成分类查看材料，具体配方见随包《咖喱食材配方》。

r6统一删除此前食材信息页中的任务领取指引及一次性奖励说明，保留合成等常规获取来源。

更新时客户端和服务端同时替换 r6 核心。独立“JEI任务奖励来源”扩展按原安装方式保留。

r4继续补齐用户指定的七项食材配方，并将特选苹果调整为九苹果，具体形状与数量见配方表。
