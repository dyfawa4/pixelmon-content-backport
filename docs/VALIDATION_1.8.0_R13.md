- 11组实际物品使用→原生糖果交互→原生进化查询/切换完成，覆盖喷火龙链、雷丘/皮卡丘、伊布分支、耿鬼交换链、幸福蛋、武道熊师、幽尾玄鱼、浩大鲸、蜜集大蛇。完整数据保留逐字段检查通过；物种/形态、特性及计算数值为对应阶段所需变化，其他字段保持。保留实际HP比例，倒下不因退化复活。
- 4组地区/雌雄分支通过实际PlayerEntity交互入口使用，再用原生糖果恢复精确原形态：阿罗拉雷丘、阿罗拉椰蛋树、喵头目、雌性幽尾玄鱼。
- 满级连续退化两次、到初阶不消耗、满级经验糖果逐阶段恢复通过。原生RareCandyEvent与EvolveEvent.Pre取消时不扣糖、不丢历史；蛋、他人、战斗、临时Mega及无前阶段边界通过。
- 个体原生NBT保存/读回和客户端物种/形态同步、中文名称、实际模型烘焙通过。
- 实际3×3配方、左下草非海草、水瓶NBT识别及拒绝其他药水、原生配方网络往返通过。

## 巢穴音乐

- 原因一：本体ExitBattlePacket仅设置battleEnded，部分巢穴退出流程不经过普通BattleScreen的音乐收尾。补上退出包的明确停止。
- 原因二：native isPlaying判断可能漏掉已排队、未激活的音乐流，而后清空song引用，导致无法清理。现按持有的实际音乐实例结束；新曲开始前清理旧实例，结束淡出不因重复退出延期。
- 实际极巨/太晶音乐对象和原生退出包、同帧启动后立即退出、排队曲目替换、重复退出、淡出完成、世界退出/断线全部通过。关闭后恢复原生背景音乐ticker。清理仅操作跟踪的对战声音实例，未调用全局停止声音；唱片、叫声等原有处理保留。
- 此为原生播放及生命周期定向验证，未声称完整复现用户未提供日志的外部偶发诱因。
