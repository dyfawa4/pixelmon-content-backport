# 全部 Mega Boss 刷新地点表（1.10.0）

基于 Pixelmon 9.1.13 与回迁 1.10.0 当前配置，合并 48 份本体表和 47 份回迁表，共 95 份有效配置、95 条记录。其中含同一 Mega Boss 生成器使用的 2 条原始回归记录。

按物种与原表明确指定的形态列出。原表未指定 X／Y 等形态的记录不拆成虚构的独立刷新表；本体和回迁中同名资源以回迁配置为准。本表汇总专用 Mega Boss 生成表，普通野生宝可梦随机成为 Boss 的路径还取决于其普通刷新表。

同一行的群系条件为候选范围；带“类”的是 Pixelmon 群系分类，可能涵盖多个原版或模组群系，保留原始标识供核对。未安装的模组群系不会凭空出现。时段“未限定”指该表没有额外限定；位置、地形和其他生成规则仍需满足。`rarity` 是候选权重，不是百分比，也不代表到点必出。
