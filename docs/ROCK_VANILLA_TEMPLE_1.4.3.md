# 1.4.3 岩石城市原版沙漠神殿

日期：2026-10-15。原版主体及布局修订已在游戏内生成；用户通过截图a5e2bad4确认“我很满意这个地图”，当前摆放效果已验收并保留。

## 实现

岩石城市中央的两个自制神殿模板改为Minecraft 1.16.5原版沙漠神殿布局，地上主体21×21格，保留双塔、阶梯屋顶、入口、橙色纹样、蓝色中心地砖，以及地下藏宝室、四个原版战利品宝箱、压力板与九个TNT。

来源为本机1.16.5 SRG JAR中的 `DesertPyramidPiece.func_230383_a_`。`tools/export_vanilla_desert_pyramid.py` 直接执行该类的生成字节码，用离线放置记录器接收填充、方块与箱子放置；不启动世界引擎。记录环境将固定地基下方视为实心地形，因此不额外延伸因悬空而生成的支撑柱；宝箱面向藏宝室内部，保留 `minecraft:chests/desert_pyramid` 战利品表，省略固定战利品种子，使每个放置后的宝箱独立抽取奖励。生成来源类与资源SHA256记录在 `resources/backport/structures/vanilla_desert_pyramid.json`。

城市适配如下：

- 两种中央广场统一为35×35格，21×21格主体居中，四周各留7格通道与前庭。清除旧神殿遗留、位置不对齐的黄色砂岩地框，外围统一连续城市铺装。
- 两个模板原有的18／25项连接器、服务及奖励NBT全部保留。A的右侧、后侧街道连接器随边界外移；与原版主体重叠的装饰／连接点移至外围通道。没有移动现有NPC实体。
- 原版的地上与地下部分分别存入中央模板及新增的 `vanilla_pyramid_basement.nbt`，以一对向下／向上的拼图连接器拼合。两处连接器完成生成后分别还原为原版蓝色地砖和空气。
- 地下片段原点为地面下14格，采用原生 `pixelmon:moving`、rigid投影、`ground_level_delta=15`、`y_hack=0`；地形计算的地面仍与中央模板一致。
- 其余430个既有自制城市模板SHA256未变。不重跑全城市生成，不覆盖已生成的玩家城市或测试存档。

## 离线验证

`tools/verify_vanilla_rock_temple.py` 已通过：

- 两个中央模板分别与地下片段拼合，逐坐标核对全部4,388个原版放置记录，包含方块状态与宝箱NBT；连接器按最终方块核对。
- 四个宝箱、九个TNT、一个压力板、蓝色中心砖和地下竖井均存在；没有固定奖励种子。
- 所有坐标在模板边界内；上下拼图接合位置、四种水平旋转的相对位置与地形地面高度一致。
- 原有连接器／服务NBT和实体保留；地面入口到街道连接器以及原有奖励箱周边均有两格高的步行通路。
- 局部更新可重复执行，结果不变；其他既有城市模板未变。
- 新增验收项：每侧留白至少7格；原版占地外、无服务NBT的位置均为城市铺装，没有旧砂岩地框。

此验证不等同于实际城市拼装与地形观感验收。完整生成、地下衔接和现场外观仍待用户方便时进游戏确认。
