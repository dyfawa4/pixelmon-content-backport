# 1.4.2 发布验证记录

日期：2026-10-14。用户确认发布此前验证的1.4.2。本版未覆盖原整合包或玩家存档，未改动任务书。

## 已完成检查

- Java11构建及 `check.ps1` 全套离线回归通过，对当前实际Minecraft、Forge、Pixelmon与可选兼容模组执行Mixin变换并校验字节码。
- NPC审计覆盖178份定义、1,444行对白、1,873份结构模板中的897个NPC和600种英文显示字符串。名称、对白、选项和不同NPC类型的取词入口分别检查，英文及未知自定义文本保留。
- 隔离完整客户端实测探测器25项标签、说明、Common、分组及根／子页面标题，均显示中文；源码中的独立QA模组不进入正式JAR或地图包。
- 真实字体下，索菲娅截图原句、十倍长句与含换行的中英混合文本通过200像素宽、46像素高边界检查。原生对白绘制截图确认原句分两行且在框内。
- 探测器列表检查中模拟位置查询新增方块实体、实体查询清空源列表，快照过滤通过；失效、异世界、未加载区块及替换对象边界保持有效。
- 高坐标引导线使用双精度相对相机位置，覆盖约15万／44万和1,254万坐标；原目标扫描配置未扩大。
- 指南针太晶搜索候选去重、非阻塞请求、真实实体确认、取消和15秒／300tick超时清理检查通过。原版要塞使用原生环状候选，负坐标和远坐标排序及可用维度检查通过。
- 太晶群系／维度候选和极巨／太晶智皮卡排除边界通过，覆盖自然刷新、普通／特殊许愿星、事件覆盖、最终分配及旧数据。原生山地阿尔宙斯资格保留。
- 城市生成区域边界与38项结构名称序列化检查通过。Lootr过期服务器／维度队列、有效当前世界项和非阻塞已加载区块查询检查通过。
- 实际补给站模板入口及蓝／绿／紫互斥抽取检查通过；10万次固定抽样为60,404／29,877／9,719。钓竿大师球NBT匹配、JEI材料展示及智皮卡查询配色检查通过。
- 合并后的捕捉计时覆盖30～2000FPS、阶段重置、时钟倒退和大数边界。无需两份独立补丁的完整客户端正常启动，进入世界日志确认JEI按协商通道恢复连接状态。
- 原有忍蛙水系增益、Mega头像、物种获得成就、城市和其他既有功能继续通过回归检查。

## 制品与人工验收范围

正式JAR的文件内容与客户端已验证构建一致。三份地图均使用当前1.4.2补丁和1.4.2手动地图控制模组，保留9／20／1张独立初始世界；不复制玩家验收世界或账号文件。

封装检查核对ZIP完整性、Java11字节码、版本元数据、源码覆盖、正式JAR一致性及SHA256。源码包排除 `.git`、`.cache`、运行日志、账号与构建结果；私有游戏内QA入口不进入正式模组或手动地图控制模组。

这些检查验证代码、资源与已观察的界面，不代表全部实际玩法已人工验收。自然巢穴搜索、捕捉动画、补给站分布、退出重进、长期单机与多人运行仍需玩家复测。已损坏区块未恢复，远传地形发黑、模型破碎及手机渲染兼容问题未确认解决。
