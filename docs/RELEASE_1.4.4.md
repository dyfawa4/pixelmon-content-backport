# 重铸内容回迁 1.4.4

2026-10-16。适用于 Minecraft 1.16.5、Forge 36.2.42、Java 11 与旧版 Pixelmon 重铸。本次交付包含独立模组、离线测试包、完整源码、构建工具和更新说明。

## 修复与改进

- **太晶巢穴捕捉与极巨巢穴一致**：移除胜利后直接判定捕获成功的分支，共用重铸原版所选球捕捉公式。保留禁球、原生扣球、成功／失败事件、太晶属性和奖励；本场爆裂场地的合法球有效倍率加 1 及提示继续生效。不同物种、球和条件的成功率仍可能不同。见 [捕捉核对](TERA_RAID_CAPTURE_1.4.4.md)。
- **神兽成就**：同行满员后直接进入 PC 也可完成物种成就；登录补查真实队伍和 PC。剑／盾之王只统计对应个体实际变形与出战，候补初始化不再连带完成，也支持场外成功变形。审计捕捉、孵化、交换、赠送、进化、变形和合体的所有者、真实存储、取消与失败条件。保留原成就 ID 和已得进度。见 [成就审计](LEGENDARY_ADVANCEMENTS_1.4.4.md)。
- **开局误得「奇装异服」**：补齐指定物种的精确条件，普通初始宝可梦不再被其他种类的材质／形态条件误判；原有闪光和特殊材质要求保持。
- **对战稳定性**：修复 Z 招式预览基础招式引用缺失造成的空指针；修复局域网中其他玩家跨维度传送误结束房主对战，保护残留选招界面的空队伍访问。普通 Z 不显示黄边，专属 Z 与队友普通招式只按爆裂场地实际作用显示，不改变之前约定的战斗规则。见 [Z 预览](CRASH_Z_PREVIEW_1.4.4.md)、[联机传送](BATTLE_TELEPORT_CRASH_2026-10-16.md)。
- **野外 Boss 禁球**：所有原生及新增 Boss 等级／颜色均复用原生 Boss 身份；补上残留精灵球分类与服务端提交前检查。拒绝投球不扣球、不消耗回合，普通野生和巢穴战后捕捉保留。
- **宝可梦编辑器中文操作**：支持中文物种、球种、招式与携带物及双语补全；保留英文输入、原生权限与保存流程，中文显示不重置已有招式 PP，重名输入提供区分。见 [编辑器说明](EDITOR_CHINESE_2026-10-16.md)。
- **Java 11 启动检查**：按实际 JVM 主版本判断，兼容不同发行商和补丁版本的 Java 11。非 11 版本显示黑底白字与黄色「警告⚠／Java11」、当前 Java 大版本及原版退出按钮，并禁止创建／加载世界和加入服务器。
- **智皮卡学习太晶爆发**：补齐 TM9 与 50 级学习资格，保留原有配招；此前另外提出的回忆师扩展适配按用户要求取消。
- **新版任务书**：去掉磁石换 300 金币的循环任务及仅服务于该兑换的 15,000 金币收费入口；保留正常磁石收集与其他任务。固定奖励共 10,000,555,850 金币，其中最终任务 100 亿，其余 555,850；扣除保留的任务金币支付额后为 10,000,523,850，扣除最终 100 亿后为 523,850。覆盖配置见 `pack-overrides/`，不清空玩家进度。见 [金币统计](QUEST_MONEY_2026-10-16.md)。

岩石城市继续使用用户满意的原版沙漠神殿布局，沿用已验收的 **97 片段快照**。保留 1.4.3 的巢穴各 50% 分流、空巢穴与已领取补给站隐藏引导线、真实府邸结构刷玛机雅娜、FTB 模组结构任务等已有修复。

## 离线包与完整源码

- `1.4.4-离线测试包-最新.zip`：本次同版本 JAR、地图控制模组、11 张干净初始地图（9 张功能图、满意版岩石城、智皮卡图）、两份任务书覆盖配置、说明和逐文件校验。安装到已有完整整合包；不含 Minecraft、Pixelmon 本体或 Java 运行时。
- `Pixelmon-Backport-source-1.4.4.zip`：完整 Java 源码、运行资源、测试、构建／打包工具、全部地图初始文件、任务书覆盖与文档。GitHub 仓库同时保存源码，版本标签 `v1.4.4` 可用于恢复；构建方法见 [BUILDING.md](../BUILDING.md)。
- 提供独立 JAR、功能包、9／21／1 张专项地图包、手册及 SHA-256。源码和离线包不含账号、令牌、玩家存档进度、原整合包或私人日志。

本机清理工具仅保留预览功能，`-Execute` 也拒绝执行；CMD 使用 ASCII 与 CRLF，PowerShell 脚本为 UTF-8 BOM，避免中文路径和换行造成误执行。未删除本机旧缓存。见 [清理工具检查](LOCAL_CLEANUP_SAFETY_2026-10-16.md)。

## 验证与安装

JDK 11 构建和整套 `check.ps1` 通过；包括真实 Pixelmon 类的 Mixin 转换、神兽成就、Z 预览、Boss、中文编辑器、联机传送及此次巢穴捕捉路径。用户已确认本轮 Java 11 客户端测试没有问题。更完整范围与尚未覆盖的多人场景见 [验证记录](VALIDATION_1.4.4.md)；第二份疑似汉化相关崩溃按用户要求仍未单独修复。

正常退出游戏和服务器，备份存档，将旧版重铸内容回迁 JAR 替换为 1.4.4；客户端和服务器使用相同版本，保留 Pixelmon 本体。任务书调整需复制功能包或离线包中的 `config/ftbquests/quests/chapters` 覆盖文件。无需另外安装已经整合的 JEI 和巢穴捕捉动画修复模组。
