# 重铸内容回迁 1.4.5 开发测试版

2026-10-17。本轮首项更新为 Pixelmon 原生 NPC 任务系统的提交、计数、条件判定及中文文案改进。适用环境仍为 Minecraft 1.16.5、Forge 36.2.42、Java 11。本文件记录开发进度，不表示已经发布 GitHub Release。

## NPC 任务改进

- 原生 39 个任务、165 个阶段全部保留，任务 ID、阶段顺序、分支、奖励及存档字段不变。原生提交和目标引擎统一修正，服务器自定义的同类 NPC 物品任务也受益。
- 提交按背包主栏与副手合计，支持整组和跨格扣取。例如要求 8 个，携带 64 个会扣 8 个、保留 56 个；3 个与 5 个可以合计提交。总量不足时一个也不扣，失败分支及展示任务不扣物品。
- 同阶段有多个提交目标时，已交的目标保留完成状态，不会因为另一个目标尚未完成而再次扣物品。
- 提交时显示物品、实际需求量、现有量或提交后的剩余量；精灵球名称保留球种 NBT。不同球种、球果颜色、指定名称、耐久和要求的 NBT 仍有区别。
- 治疗仪和 PC 的颜色作为外观处理：制作、使用、持有和提交识别同功能颜色变体。不会将治疗仪与 PC、其他模组同名物品或不同颜色的球果混为一类。
- 合成、烧炼、拾取、丢弃和采收按本次实际物品数量累计；一次获得多个物品不再只算一次。方块使用、破坏、放置依然按发生次数累计。
- 持有和未持有目标按所需总量实时判定，满足时立即完成，不通过反复扫描不足数量来累计进度。主栏与副手统一检查，避免原版单格和双 tick 阶段问题。
- 原生球类制作教学、治疗仪／PC 制作教学、大师球取得教学和钢铁的制球准备阶段认可已随身携带的所需物品，准备阶段不扣物品；钢铁实际收球时才扣。其他自定义制作任务以及捕捉、战斗、进化、采收等行为目标继续要求真实事件。
- 已处于目标维度时，约一秒内补查，无需先离开再回来。结构任务增加已登记模组结构的原生结构记录兼容。
- 日期范围包含首尾日期，并支持每年重复及跨年范围；游戏时刻范围支持跨午夜。没有缩短钢铁等待时间、取消季节限制或直接完成传说捕捉任务。
- 原版遗漏数量导致的负数物品目标在收到相关事件时恢复为一次目标，不重置任务阶段或已有正常进度。

## 汉化核对

任务与相关 NPC 界面共 941 个英文键（含本轮 3 个提示键），中文键无缺失。所有原生任务对话引用可解析，参数占位符及动态数量符号一致。按用户要求保留原版剧情、对话和任务描述；原有语言覆盖与1.4.4逐键相同。操作说明与验收断言只放入独立测试地图辅助模组，不进入正式游戏任务文案。

扩大扫描本体与附加模组的有效英文键后，补齐本体原有的 55 个中文缺失键，涉及形态、状态、命令、进化条件及音乐唱片；另翻译了 Mega/Boss 的两处普通界面标签。空白的两项上游描述保持空白；MissingNo、Pixelmon、Discord、作者名和网址等专名保留。当前有效英文键均有对应中文键，不代表所有第三方模组或自定义服务器文案都已逐屏人工检查。

## 测试与使用

JDK 11 生产构建与整套 `check.ps1` 通过。专项测试执行了真实本体经 Mixin 转换后的任务方法、原生奖励和阶段流程，并以受控背包／世界服务验证，含 1,000 组随机扣取、颜色、NBT、失败、重复提交、跨年及跨午夜边界。覆盖清单见 [验证记录](VALIDATION_1.4.5.md)，任务与语言静态明细见 [审计数据](NPC_QUEST_AUDIT_1.4.5.json)。

测试 JAR：`dist/pixelmon-content-backport-1.16.5-1.4.5.jar`。客户端与服务器应使用同一版本，退出游戏并备份存档后替换旧附加模组，保留 Pixelmon 本体。无需清空任务进度。用户已确认NPC专项测试没有问题，并授权制作离线包；当前未发布1.4.5 GitHub Release，正式1.4.4文件与标签保留。

## 太晶化外观回迁（持续验收）

新增高版本官方 19 属性冠冕、跟随实际头部蒙皮姿态的挂载、中央头部表面贴合、属性色三角晶面、闪烁与边缘反光，身体体型不变。包括自制戴帽皮卡丘正常／异色，保留厄诡椪和太乐巴戈斯专属形态。变身复用原版进化／Mega 光束；临时视觉状态及起始 tick 由服务端同步，当前协议为 10。

独立测试模组加入 F8 外观图鉴，可搜索全部物种、形态和异色，切换 19 属性、原型对照、旋转缩放、动画和截图。测试模组不进入正式主 JAR。当前身体使用保留原配色的薄结晶表层，属性色集中于边缘及局部移动反射，白色高光收窄到中心，以改善属性区分而避免整身染色；全物种、多人和性能验收尚未全部完成，详见 `TERA_VISUAL_VALIDATION_1.4.5.md`。

太晶外观 r10 已获本轮用户认可，全物种、多人及性能验证范围仍按验证文档保留。

## 大器晚成成就

新增「大器晚成」分支，包含快龙、班基拉斯、暴飞龙、巨金怪、烈咬陆鲨、三首恶龙、普通／洗翠黏美龙、杖尾鳞甲龙、多龙巴鲁托、戟脊龙共 11 项。单项名称直接使用宝可梦名字；完成任意一个单项即可解锁「大器晚成」开篇，不要求集齐。捕捉、进化、交换、赠送及真实入库均可计入，更新前同行／PC 中已拥有的目标登录补查。保留已得进度，普通与洗翠黏美龙分开。详见 `LATE_BLOOMER_ADVANCEMENTS_1.4.5.md`。

## 帽皮珍贵球保护

自制小智版皮卡丘正常／异色仅拦截大师球、起源球、公园球。对战内在选择提交前拒绝并恢复菜单，不消耗球或行动；场外不进球，播报原因，沿用 Boss 拒绝块退回该颗原本可退的球，防止丢失与重复返还。其他球、普通皮卡丘和其他物种保持原捕捉逻辑。构建、完整回归和 21 次场外真实碰撞验证通过，详见 `CAP_BALL_GUARD_1.4.5.md`。

「宝可梦：轻快之旅」正式主界面及各类奖励空气问题继续登记于 `UPDATE_1.4.5_PENDING_TASKS_2026-10-17.md`，逐项推进。
