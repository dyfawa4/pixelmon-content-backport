# 无敌神剑（1.9.0）

独立物品ID：`pixelmon_backport:divine_sword`。

- 自制立体剑模型：银白分面剑刃、青色符文、内收的金色护手、紫色握柄与宝石。尖刃替换首版平头，库存显示增加侧面角度，手持和展示框使用同一套模型。
- 耐久3。左键攻击末影龙（包括头、身体、尾及翅膀）或凋零时，一击致死；每次成功击杀扣1次，第三次后损坏。
- 对其他所有实体取消攻击，不造成伤害、不扣次数。已经死亡或进入死亡动画的Boss重复命中也不扣次数。
- 处理末影龙部位减伤、飞行阶段致命伤后的1HP过渡和凋零出生无敌期；保留原生死亡、玩家击杀归属、掉落和末影龙死亡动画，不直接删除实体。
- 禁止附魔台、铁砧附魔及修复、材料修复和工作台双物品修复；经验修补与耐久不能增加可用次数。已用次数独立保存在物品数据中，外部附魔和Unbreakable标记会在服务端清理。
- 不添加配方、自然掉落、商人交易或普通战利品。管理员可用于任务商店／任务奖励，创造列表可找到。

## 配入任务商店

取得一把全新神剑：

```mcfunction
/give @s pixelmon_backport:divine_sword 1
```

在FTB任务编辑模式中，选择该物品作为商店的物品奖励即可。不需要附加攻击力、耐久或附魔NBT；由物品本身负责限次和Boss击杀机制。商店价格与购买条件由任务书配置决定。

物品栈的原生SNBT表示为：

```snbt
{id:"pixelmon_backport:divine_sword",Count:1b}
```

任务编辑时请使用全新物品，避免把已经消耗过次数的剑保存为商店奖励模板。已有旧版无敌木剑不会自动转换。

当前属于本地1.9.0开发内容，客户端和服务端须同时更新对应核心。此前作者道馆分布调整同时保留。
