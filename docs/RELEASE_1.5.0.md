# 重铸内容回迁 1.5.0

适用于 Minecraft 1.16.5、Forge 36.2.42、Java 11 和 Pixelmon 旧版本体（已验证文件名 9.1.13、内部版本 9.1.12）。本版合并全部未发布的 1.4.5 改动；没有独立的 1.4.5 正式版。已发布的 1.4.4 保留。

## 更新内容

- **乘骑重构**：空格即时起飞／上升，释放悬停，沿用下降键，落地后不自动再次起飞；地面起跳、水面浮力、转弯及服务器同步重做。人物显示位置与视角依据动画模型调整，保留原碰撞箱和物理乘客位置。原本不可骑、不可飞的资格保持；下骑自己的宝可梦后可以立即换乘。
- **太晶外观**：19 种冠冕跟随头部动画并贴合头部表面；身体保留原配色，增加晶面、属性色反光和闪烁，支持自制戴帽皮卡丘。独立测试客户端提供 F8 外观图鉴，正式核心不包含图鉴和自动测试。
- **NPC 任务与对话**：物品按主栏、副手总量提交，支持整组和跨格扣取；不足不扣、重复提交不重复扣。完善颜色变体、事件数量、持有、维度、日期与跨午夜条件，保留原任务阶段、奖励和故事文案。修复等待状态导致“再见”或提交卡住的问题，并补齐相关汉化。
- **大器晚成成就**：新增 11 个获得成就，名称使用宝可梦名字；普通与洗翠黏美龙分别记录。捕捉、进化、交换、赠送和真实入库均可计入，登录补查队伍与 PC。完成任意一项即可解锁“大器晚成”开篇。
- **帽皮珍贵球保护**：只拦截大师球、起源球、公园球。对战内阻止提交，场外复用 Boss 不进球与拒绝提示、返还路径，其他球保持原逻辑。
- **奖励清理**：移除 Boss、奖励箱、巢穴等路径中的空气／无效物品，保留合法无掉落结果、数量和 NBT。道馆徽章等特殊奖励继续与其他奖池隔离。
- **道馆主用药**：仅将活力碎片换成活力块，保持原次数预算、AI 时机及其他用药逻辑。
- **主菜单背景**：替换为用户提供的村庄与戴帽皮卡丘图片，原 Minecraft / Java 标题、按钮、字体和布局不变，不加版本字样。

保留 1.4.4 的对战、成就、中文编辑器、Java 11 检查、任务书覆盖和已验收岩石城等内容。本版不包含追加的第三方小地图兼容修改。

## 安装

正常退出游戏和服务器并备份存档，删除旧回迁附加模组 JAR，换入 `pixelmon-content-backport-1.16.5-1.5.0.jar`；保留 Pixelmon 本体。服务器和所有客户端必须使用同一版本。无需清空任务和成就进度。

功能包附带原有两份 FTB 任务书覆盖，按需复制 `config/ftbquests/quests/chapters`。离线测试包额外包含干净测试地图与辅助模组，只供独立测试实例；正式实例仅安装核心 JAR。地图辅助模组、F8 图鉴与自动检查工具不能当作正式玩法要求。

完整源码、构建工具、资源和 SHA-256 一并提供；不包含 Minecraft、Pixelmon 本体、账号或玩家进度。上游素材归属见 `THIRD_PARTY.md`，构建见 `BUILDING.md`。

## 验证范围

Java 11 编译、Mixin 检查及本轮任务、帽皮球保护、奖励、对话和乘骑的针对性验证通过，用户已完成主要功能的实机验收。乘骑最新简测包含大岩蛇连续原生重新上骑、飞行转向及水上切换。

未宣称所有宝可梦的每种动画、所有多人网络条件均逐项实测。详见 [验证记录](VALIDATION_1.5.0.md)。
