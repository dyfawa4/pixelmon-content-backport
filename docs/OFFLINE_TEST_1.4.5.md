# 1.4.5 离线测试包：先读我

构建标识：`1.4.5-offline-test-20261017-r1`。包含NPC任务系统重构和汉化补全，沿用1.4.4已发布的其他修复。用户已确认本轮NPC专项测试没有问题。**原有NPC剧情、任务描述和对话保留；“64交8”等验收说明仅出现在独立测试地图。**

本包安装到已有完整整合包，不含Minecraft、Forge、Pixelmon本体、启动器或Java。适用Minecraft 1.16.5、Forge 36.2.42、Java 11、本体文件名9.1.13／内部9.1.12。

## 安装

1. 正常退出游戏，备份存档，建议先使用整合包测试副本。
2. 从mods移出旧版重铸内容回迁主JAR和旧版地图辅助JAR，避免不同文件名的同一个模组重复加载。保留Pixelmon本体和整合包其他模组；已整合的旧JEI／巢穴动画独立修复不需重复安装。
3. 复制本包mods中的3个JAR：主模组、原地图控制、新NPC专项控制，三者各保留一份。**普通游玩只需主模组；两份地图辅助模组只用于验收地图。** 联机双方主模组版本一致。
4. 将saves中的12个世界目录复制到实例saves。同名旧测试世界请先改名保留，不要合并存档文件。进入“回迁NPC任务 1.4.5 手动验收”测试本轮内容，右键彩色方块准备，再与对应NPC对话。
5. 对同版新版“电脑端”任务书，备份后复制config中的两份章节覆盖，继续保留1.4.4的磁石循环兑换移除。自行修改过的其他任务书版本请先比较文件；不需要清空任务进度。
6. 必须用Java 11，通过原启动器启动。不同厂商的11.0.x均可，非11版本会被提示页拦截。

## 地图与内容

共12张干净初始地图：原9张功能图、已验收岩石城、智皮卡专项图、1.4.5 NPC任务专项图。岩石城继续是原版沙漠神殿布局的97片段快照，没有重新生成；文件夹中的旧版本标识是地图ID，不表示使用旧模组。

NPC专项包含真实NPC、原生提交与奖励流程：64扣8、3＋5合计、7个不足、错误球种、展示不扣、多目标分别提交，以及不同颜色治疗仪／PC、实际制作和持有总量测试。成功得到1颗绿宝石，准备台可以重新测试。详细操作见NPC_QUEST_TEST_MAP.md。

正式任务ID、阶段、奖励与原剧情文案保留。无需拆分整组物品；正常游戏不会出现测试任务名和“不应扣物品”等验收断言。包内两份测试辅助模组不要作为普通游戏补丁推荐给其他人。
