# 重铸内容回迁

**为 Minecraft 1.16.5 的旧版 Pixelmon 重铸补充新宝可梦、新形态和太晶玩法。**

这是一个独立附加模组，在保留重铸本体与整合包的基础上加入新种类、ZA Mega、道具、场外变形、太晶战斗和中文资料。

`1.7.0 正式版` · `Minecraft 1.16.5` · `Forge 36.2.42` · `Java 11` · `Pixelmon 9.1.12～9.1.13`

**[下载 1.7.0](https://github.com/dyfawa4/pixelmon-content-backport/releases/tag/v1.7.0)** · **[1.7.0 完整更新内容](docs/RELEASE_1.7.0.md)** · **[玩法手册](HANDBOOK.md)** · **[测试地图指南](TEST_MAPS.md)**

客户端与服务端同时替换旧回迁核心，只保留一份。本包不是完整客户端，不需要独立资源包；首次启用可选忍蛙增强时双方都要安装，默认不启用。

## 1.7.0 更新

- **作者道馆与 AI**：专属群系／维度队伍、参战限制、常驻蚀和命中规则；优先可靠击倒，最后一只无法先手收割时优先复活王牌。作者奖励固定大师球、50万～100万币和五份不重复奖池，首次必得智蛙石，此后1%。加入备战设施、林地府邸箱和作者十胜挑战。
- **宝可梦与战斗**：太乐巴戈斯三形态、携面具厄诡椪场外太晶、奈克洛兹玛场外究极爆发；修复入场HP与探索崩溃。新增基格尔德三项成就，修复图标，调整新增神兽性别和灵幽马权重。
- **忍蛙与智皮卡**：普通／小智Mega石分离，基础与可选增强模式分离，孤忍自修增加下回合优先度；雷之誓约统一实际克制、播报与技能着色，修复智皮卡生成／查询并完善捕获、偏好球与掉落。
- **Boss与巢穴**：七级Boss成就、溺水+60与常驻蚀、终极+50奖励；多入口治疗清蚀与状态面板；星块双巢穴兼容、音效、1星双矿石及5星奖池、究极异兽群系边界。
- **音乐与界面**：独立“宝可梦音乐”滑条控制所有重铸音乐，野生双曲、馆主／极巨／太晶配乐、中心／商店音乐方块；唱片图标与说明修订，定制主页标题，固定“b站端忆制作”。
- **探索与稳定性**：末地超能城市布局和异步定位、全年溺水入口、探索箱与新配方、初次制作选色、JEI实际来源、材料任务、PC／队伍同步、战斗背包与TrashSlot兼容。

完整规则、安装方式及验证边界见 [1.7.0 发布说明](docs/RELEASE_1.7.0.md)。更新内容按主题统一整理，以下保留旧版本发布记录。

修复太晶巢穴合法遭遇被清空、无法挑战的问题；空太晶巢穴与空极巨一样隐藏引导线，有遭遇后恢复。主世界生产分流独立抽样160万次，太晶50.038%、极巨49.962%，不修改各50%的分流规则。

小智忍蛙详情页和对战侧栏统一显示每击基础威力20，结束加成只播报一次；修正牵绊进化测试点。幸运方块排除MissingNo和未启用宝可梦。

FTB“发现结构”任务补齐模组结构类型注册 ID 的识别，沿用原任务前置、进度和奖励；与野生戴帽子皮卡丘开战时提示三种禁止使用的捕捉球，每场每位玩家只提示一次。跳过 Lootr 装饰赞助名单的启动联网下载，避免该请求无超时等待。

功能包不附带 Pixelmon 本体；测试地图单独下载。地图 ZIP 顶层直接是 `mods/` 与 `saves/`，将 `saves` 下选定的世界文件夹复制到实例中，避免再套一层目录。
