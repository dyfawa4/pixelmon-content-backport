# 重铸内容回迁

**为 Minecraft 1.16.5 的旧版 Pixelmon 重铸补充新宝可梦、新形态和太晶玩法。**

这是一个独立的附加模组：在保留旧版重铸本体与整合包的基础上，加入新种类、ZA Mega 形态、携带道具、进化物品和中文资料，并提供太晶战斗、独立太晶巢穴及对应获取渠道。适合希望继续使用 1.16.5，同时体验更多新内容的玩家。

`1.5.0 正式版` · `Minecraft 1.16.5` · `Forge 36.2.42` · `Java 11`

**[最新版本：1.5.0](https://github.com/dyfawa4/pixelmon-content-backport/releases/tag/v1.5.0)** · **[完整玩法手册](HANDBOOK.md)** · **[测试地图指南](TEST_MAPS.md)**

## 1.5.0 更新

重构乘骑操控、转向、模型座位和视角；新增 19 属性太晶冠冕及晶体外观；完善 NPC 任务提交与对话恢复，加入“大器晚成”获得成就和帽皮三种珍贵球保护；修复空气奖励，隔离道馆徽章奖池，馆主复活道具换为活力块。主菜单只更换背景。

原乘骑／飞行资格、碰撞箱和既有玩法保持。全部未发布 1.4.5 内容并入 1.5.0，1.4.4 作为旧正式版保留。详见 [更新说明](docs/RELEASE_1.5.0.md)、[验证范围](docs/VALIDATION_1.5.0.md) 和 [乘骑测试地图](RIDING_TEST_MAP.md)。

## 1.4.4 更新

修复神兽入 PC 成就、候补剑／盾之王误完成、普通初始宝可梦误得「奇装异服」、Z 招式预览与联机传送崩溃，以及所有等级野外 Boss 的选球限制。宝可梦编辑器支持中文操作，新增兼容各发行商的 Java 11 检查，补齐智皮卡太晶爆发学习资格。太晶巢穴移除保证捕获，与极巨巢穴共用原版捕捉公式。

新版任务书移除磁石换 300 金币的循环与专用收费入口，附统计及覆盖配置。完整源码、离线测试包与更新内容一并交付；岩石城保留用户满意的 97 片段快照。详见 [发布说明](docs/RELEASE_1.4.4.md)、[验证记录](docs/VALIDATION_1.4.4.md) 和 [源码构建](BUILDING.md)。

## 1.4.3 更新

修复太晶巢穴合法遭遇被清空、无法挑战的问题；空太晶巢穴与空极巨一样隐藏引导线，有遭遇后恢复。主世界生产分流独立抽样160万次，太晶50.038%、极巨49.962%，不修改各50%的分流规则。

已由当前玩家领取且尚不可再次领取的补给站隐藏引导线，冷却结束后恢复；多人领取状态分别判断，标记和信息保留。

玛机雅娜按真实林地府邸结构刷新，取消黑森林限定，保留其他原生条件；已核对超多生物群系的5个府邸群系共用原版结构登记，玩家自建房屋不算。

小智忍蛙详情页和对战侧栏统一显示每击基础威力20，结束加成只播报一次；修正牵绊进化测试点。幸运方块排除MissingNo和未启用宝可梦。

岩石城改用原版沙漠神殿，35×35广场居中，四周留7格并清理旧黄色地框。城市地图包包含用户已验收的97片段岩石城快照，进入即为满意的那张布局，不重新随机组装。

FTB“发现结构”任务补齐模组结构类型注册 ID 的识别，沿用原任务前置、进度和奖励；与野生戴帽子皮卡丘开战时提示三种禁止使用的捕捉球，每场每位玩家只提示一次。跳过 Lootr 装饰赞助名单的启动联网下载，避免该请求无超时等待。

完整变化见[1.4.3发布说明](docs/RELEASE_1.4.3.md)，验证范围见[验证记录](docs/VALIDATION_1.4.3.md)。

## 1.4.1 已有内容

小智版甲贺忍蛙的飞水手里剑先赋予仅自身的水系攻击50%加成，当回合立即受益，持续三回合；重复只刷新时间，到期播报结束。新增「殊途同归」与「凌云九霄」成就。修复多人游戏崩溃、智皮卡平原村庄刷新／查询及概率说明，固定公性并保证野生击败奖励；巢穴排除智皮卡。补齐双罗盘中文，统一Mega像素头像，新增罕见／传说补给站自然替换，并改善任务数据失步后的恢复。

**[忍蛙技能与成就详细说明](docs/GRENINJA_1.4.1.md)** 包含适用形态／特性、每击20→30、固定3击、当回合加成、三回合计时、刷新与清理，以及「殊途同归」的真实获得条件。

**[智皮卡与智皮卡 Z 详细玩法](docs/CAP_PIKACHU_1.4.1.md)** 包含独立身份、完整属性、技能池、平原村庄获取、刷新概率、捕获率3、禁球、晶石配方、Z使用步骤、留1HP/全力攻击、爆裂倍率与持续、变属性招式及黄色边框。

发布包含正式补丁、功能包、三份地图包、完整手册、智皮卡及忍蛙专项说明、完整源码与校验文件。完整变化见[1.4.1发布说明](docs/RELEASE_1.4.1.md)，验证见[发布验证记录](docs/VALIDATION_1.4.1.md)。任务书目标、奖励与任务条件由任务书维护者处理，本版不修改。

上述文件可从 [1.5.0 Release](https://github.com/dyfawa4/pixelmon-content-backport/releases/tag/v1.5.0) 下载，也可由构建脚本生成到 `dist/`。

1. 准备 Minecraft **1.16.5**、Forge **36.2.42**、**Java 11** 和旧版 Pixelmon 重铸本体。已验证文件名为 9.1.13、内部版本为 9.1.12 的本体。
2. 关闭游戏与服务器，备份存档；升级时移除旧版回迁功能模组，只保留一份。
3. 解压功能包，将 `mods/pixelmon-content-backport-1.16.5-1.5.0.jar` 放入实际游戏实例的 `mods` 目录，然后启动游戏。多人游戏中，服务器和所有客户端使用相同版本。
4. 如需道具查询，安装 JEI **1.16.5 / 7.x**；如需测试地图，按 [地图指南](TEST_MAPS.md) 安装独立地图包。

本版已集成JEI连接及巢穴捕捉动画修复，移除旧的 `pixelmon-jei-fix` 和 `pixelmon-raid-catch-fix` 独立补丁，保留JEI依赖。

功能包不附带 Pixelmon 本体；测试地图单独下载。地图 ZIP 顶层直接是 `mods/` 与 `saves/`，将 `saves` 下选定的世界文件夹复制到实例中，避免再套一层目录。

## 1.2.0 更新

- 八座新城补齐道馆内装、观战席、照明、街景和正式门；门口与门后保留净空。
- 补齐原生 NPC 中文对白、成就头像和大师球分组入口；JEI 正文为黑色，Shift 详情为灰色。
- 新增十八属性 `/locategym` 命令及探险家指针入口，筛选真实主道馆属性。

- 新增可改键的场外 Mega 进化，默认 J；支持原生及回迁进化石，收回、进入战斗或重进时还原。
- 六种合体成就补充双方、道具和形态说明；新增无极巨化成就。
- 合并快龙进化石的重复展示与获取入口，兼容旧存档；十八张城市地图补齐传送交互台。

补齐十八种属性道馆与各自徽章，新增八座不同布局、配色与地标的主题城市，保留原城市服务 NPC、商店、宝可梦中心与物资设施。补齐原有部分馆主缺失的徽章奖励，新增徽章支持 Shift 和 JEI 查询。提供十八张独立城市地图及全部徽章展示世界。

优化实力相当 NPC 的对战逻辑。

物品详情统一灰色；已充能太晶珠显示原版附魔光泽，说明分成三行并统一治疗仪用语。移除重复的快龙进化石，旧存档中的重复石自动转成保留的版本。新增骑乘配置、104 项捕捉、6 项原生合体及无极巨化成就，提供独立复测地图。
